# 星烽 StarBeacon 研判处置确认

管理员可基于本人已完成研判的源 IP 封禁候选，明确确认一次限时处置。该操作生成独立授权档案和签名任务，执行探针使用通用 HTTP 连接器访问设备。历史影子结果保持 `execution_authorized=false`；授权与设备配置、实际流量效果分别记录。

## 操作入口与资格

在“模型配置 → 评估记录”中查看匹配的 `block_source` 评估，点击“处置确认”。页面使用一个评估表格和一个弹窗，不开放目标 IP 编辑，不直接调用模型或设备。

弹窗读取本人已有授权；存在授权时只读展示原任务、探针注册代次、连接器、期限、依据和摘要。没有授权时，完整分页读取探针目录，只提供最近 35 秒内观测有效、在线启用、具备 `response.block` 能力与就绪连接器的探针。多探针时由管理员选择执行位置；只有一个合格探针时预选。管理员填写 30–3600 秒且不超过设备限制的期限、1–500 字符依据，并勾选确认。

提交时服务端重新读取实际 ES 告警白名单；模型自报分数仍不代表经校准的攻击概率。本入口提供显式人工确认；持续策略的自动授权由[持续决策与自动授权](持续决策与自动授权.md)独立记录，多级审批尚未提供。

## 当前材料核验

| 核验对象 | 拒绝条件 |
| --- | --- |
| 账号 | 非启用管理员、租户停用、凭据修订或角色失效、跨创建账号读取 |
| 原评估 | 摘要不一致、到期、未来时间、不是匹配的源 IP 封禁候选、同一评估已有其他授权 |
| 策略 | 当前头修订、定义摘要变化，或已停用；不使用历史头替代当前配置 |
| 本人研判 | 到期、取消、未成功、作业标识或冻结材料变化；重新评估结果必须与原判断一致 |
| 实际告警 | 原始事件身份不一致、冻结白名单摘要改变、缺失、材料观测超出策略时限 |
| 探针 | 注册代次变化、离线、健康观测过期、签名信任不符、能力缺失 |
| 连接器 | 身份、配置摘要、就绪状态或期限限制不符；探针再次核对允许地址、保护网段与管理通道 |

材料核验不读取原始载荷，不因历史匹配跳过当前资格，也不把无法核验视为安全或可执行。

## 原子提交与未知结果

`POST /api/v1/decision-evaluations/{id}/response` 要求 CSRF 和唯一的规范 `Idempotency-Key`。请求严格包含 `evaluation_sha256`、`sensor_id`、`registration_id`、`connector_id`、`config_sha256`、`ttl_seconds`、`reason`、`confirmed` 八个字段，重复、大小写别名、未知字段和超过 8 KiB 的输入拒绝处理。

租户事务内同时提交授权档案、签名 `response.block` 任务、任务审计与 `decision.response.confirm` 审计。任一失败不留下可投递任务。每实例最多两个并发处置确认；设备任务共享租户滚动 24 小时 1024 项预算与同一设备目标在途约束。

每个评估只能授权一次。原键及原输入再次提交返回原授权、原任务和原期限；不补发、不续期、不再次请求模型，也不依赖已经回收的研判或设备状态。当前账号资格仍需有效。更换键、目标探针或期限不会创建第二次授权。

网络中断、503 或回执缺失时，前端锁定原输入和原键，提供“核对原提交”。收到完整且与原评估、当前账号、输入和全量摘要一致的回执后才显示受理。确定的业务拒绝允许修正后再次确认；切换账号、页面或关闭读取会取消请求并忽略迟到结果。浏览器刷新后的历史核对通过 `GET .../response` 完成，不声称浏览器本地保存了未知提交的持久恢复凭据。

## 档案与执行边界

独立 `decision-response.v1` 档案固定原评估、策略修订、定义、研判、材料摘要、原目标、执行位置、确认人、时间、输入与任务标识。默认按 `operations` 保留 180 天，支持分类期限配置；配置只影响未来对象。运行角色没有 UPDATE 权限，未到期记录不能删除，到期记录由有界保留维护清理。研判、评估和任务各按自己的期限保留，回收原材料不改写尚未到期的授权。

202 表示平台已受理，200 表示原提交确认。任务记录用于核对设备独立回读与条件解除。通用连接器要求设备提供独立租约、原生 TTL 和条件解除；受控 Docker HTTPS 协议端点不能证明真实防火墙、EDR 或实际流量阻断。协议、保护地址、到期及未知写入规则见[HTTP 联动与限时封禁](HTTP联动与限时封禁.md)。

授权档案的“查看任务记录”使用原 `task_id` 打开 `/sensors?view=tasks&task=<任务标识>`。任务详情独立读取，不受最近 200 项列表上限影响。原执行截止与记录保留截止分别显示；默认操作数据保留 180 天，已删除或已过留存期时展示不可访问，不将缺失任务推断为未执行，也不再创建授权。原设备离线时仍可查看档案，后续回读和解除必须重新核对当前注册身份、连接器配置及独立执行条件。
