# 星烽 StarBeacon 检索快照与元数据导出

告警与协议记录页面提供「导出」入口，使用最近一次已提交的检索条件。弹窗冻结这些条件；编辑尚未提交的筛选项不改变导出范围。当前提供同步、完整、有界的元数据 CSV；原始报文与 PCAP 使用独立的原包取证流程。

## 查询与完整性

平台只接受各页面已有的查询字段，时间为 `[start,end)`，跨度不超过 31 天。索引、租户与数据集由当前身份确定，客户端不能指定任意索引或租户。`page` 与 `page_size` 按列表契约校验，导出读取全部匹配记录，不只导出当前页。

每次导出创建 Elasticsearch PIT，以 500 条为一批按 `_shard_doc` 升序读取，使用精确整数字符串传递 `search_after`。查询期间写入并刷新的记录不会进入已创建的快照，因此导出数量可能与此前列表或下一次查询不同。每批使用最新返回的 PIT 身份；完成、超限、错误或客户端取消后均有界关闭快照。

必须确认完整分片、精确且稳定的总数、完整批次、严格递增的排序游标，以及记录的索引、租户、标识、数据集和时间范围。PIT 建立时核对总分片、成功分片、跳过分片及失败分片；时间条件可能裁剪历史索引，后续搜索必须覆盖建立时「总分片减跳过分片」的全部有效上下文。跳过数量缺失、负值、超过总数，或有效上下文减少／增加，均拒绝导出。重复记录、超时、部分分片、来源不一致或快照关闭未确认，均返回错误，不提供可下载的部分结果。无匹配索引或所有历史索引均被合法裁剪的成功空快照生成只有表头的文件；依赖故障不会被解释为空结果。

当前限制为 **10,000 条、8 MiB**，二者任一超限均拒绝整个文件，用户需缩小时间范围或增加条件。快照读取最长 45 秒，HTTP 准备流程最长 50 秒；快照关闭另有 3 秒清理预算。上述值是资源边界，不是响应时间或大流量 SLA。

## 文件格式

CSV 使用 UTF-8 BOM、CRLF 和标准 CSV 引号转义，固定 28 列：事件标识，事件／采集／接收时间，探针／注册／来源代次，来源偏移、序列，源／目的 IP、端口、MAC，传输／应用协议，事件类型、级别，规则 SID／修订／名称，HTTP 方法／主机／路径，流标识，原文 SHA-256 和证据状态。时间为 UTC 并保留已有纳秒精度；没有观测时间的字段为空，不生成到站、离站或解密时间。

不包含原始 EVE、请求响应载荷、PCAP 字节或模型推断。忽略前导空白、控制字符和 BOM 后以 `=`、`+`、`-`、`@` 开始的单元格添加文本前缀；超过 15 位的纯整数字符串也以文本保存，避免表格软件执行公式或丢失精度。文本前缀属于文件格式，不能作为原始字段字节进行证据比较。

响应提供文件长度、SHA-256、数据集、记录数和精确时间范围。浏览器完整接收后验证长度、摘要、UTF-8 BOM、数量边界及纳秒范围，再提供保存入口。验证失败、会话变化或取消不会触发迟到下载；弹窗保留业务错误。浏览器发起保存不等于文件已写入用户磁盘。

导出确认窗列出已提交的筛选条件及协议来源标识；长表达式可在有界区域滚动查看。导出执行中保持原始条件，未提交的表单编辑不改变文件范围。未设置其他条件时明确显示时间窗口内的全部记录。

## 身份、额度与审计

管理员和只读账号可导出当前租户的同一元数据范围；敏感原文不随元数据授权开放。接口使用同源 POST、CSRF 与当前会话，批次前后、审计前及交付前回读身份、角色、凭据修订和会话状态。已生成且交付到客户端的文件无法被远程追回；撤权只能阻止后续平台访问和未交付导出。

每进程同时最多两个导出、同租户一个。配置 Redis 时使用 60 秒技术租约约束跨进程同租户并发；额度不可核对时拒绝，释放仅删除当前执行者的租约。技术租约不属于 180 天业务留存；没有 Redis 的单进程测试不会被视为集群额度验证。

完整文件准备成功且快照关闭后，通过当前用户事务记录 `search.export.prepare.alerts` 或 `search.export.prepare.context` 操作审计；记录表示「文件已准备」，不声明客户端接收成功。审计不可写或用户已变化时不交付文件。业务操作审计默认保留 180 天，遵循用户自定义留存策略。

## 接口与验收边界

`POST /api/v1/alerts/export` 和 `POST /api/v1/traffic/export` 详见 [平台 OpenAPI](../api/openapi/platform.json)。无效条件返回 400，失效会话返回 401，同源／CSRF 失败返回 403，超限返回 413，额度占用返回 429，依赖或完整性失败返回 503。

真实集成用例验证两页 PIT 读取、快照期间写入刷新、跨租户隔离、协议来源条件、空索引、历史索引全部及部分裁剪、CSV 字节与摘要、准备审计、故障、撤权和 Redis 额度。同源码完整后端回归及 90% 覆盖率门禁通过。后端 `7d419215…`、前端 `efb50868…` 的实际 ZIP 部署后已在浏览器下载空结果与两条告警 CSV，核对 UTF-8 BOM、CRLF、28 列和原始文件摘要；八档 PC 宽度的导出弹窗具有真实对话框和遮罩，位于页面外容器。历史组件绑定缺陷和早期不合格的尺寸采样独立保留；本次记录见[测试覆盖与验收记录](测试覆盖与验收记录.md)，不认定全部导出异常、全页面状态或生产验收通过。

列表仍使用前 10,000 条有界分页，不共享导出的持久 PIT；异步海量导出、原生包／完整会话统一快照、资产级授权、导出任务恢复与保全均待实现，不能将本功能认定为完整调查导出需求已验收。

Elasticsearch 官方 REST 契约使用 `POST /{index}/_pit` 创建、`DELETE /_pit` 关闭，并要求后续使用最新 PIT 身份。实现使用官方 Go SDK，参考 [创建 PIT](https://www.elastic.co/docs/api/doc/elasticsearch/operation/operation-open-point-in-time) 和 [关闭 PIT](https://www.elastic.co/docs/api/doc/elasticsearch/operation/operation-close-point-in-time)。
