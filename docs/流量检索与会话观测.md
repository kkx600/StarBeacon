# 星烽 StarBeacon 流量检索与会话观测

流量检索读取当前租户已入库的 Suricata 协议事件和会话摘要。主平台入口为 `/traffic`，管理员和只读账号均可使用；原始 EVE 仅管理员可读。页面采用条件表单、一张分页列表及详情弹窗，加载、依赖失败和无匹配记录分别呈现。

## 数据与检索

告警保存在 `sb-alerts-<tenant>-<date>`，协议记录保存在 `sb-context-<tenant>-<date>`。接口固定租户、数据集和事件类型，不接受客户端索引名称或任意 Elasticsearch DSL。支持 flow、HTTP、HTTP/2、DNS、TLS、QUIC、SSH、SMTP、FTP、SMB、NFS、DHCP、RDP、协议异常和文件元数据。列表只包含探针实际开启日志并已成功入库的类型；支持检索类型不表示所有协议都有完整检测规则或原包证据。

托管捕获配置明确启用 HTTP 和 TLS 扩展日志，以记录实际请求方法和 TLS 协商元数据；不启用全量请求头、认证头或证书链记录。已有外部 EVE 若缺少方法等字段，显示缺测，不从另一条告警补造协议事务。HTTP 扩展字段的配置依据为 [Suricata 8.0.7 EVE 输出配置](https://docs.suricata.io/en/suricata-8.0.7/output/eve/eve-json-output.html#http)，实现与原生测试均核对该配置。

规范化优先保留实际 `app_proto`。HTTP、DNS、TLS 等明确协议解析器产生的事务事件可能省略该字段，此时仅按固定协议事件白名单设置 `network.protocol`，使协议筛选和高级字段的协议约束一致。`flow`、`alert`、`fileinfo`、异常和统计事件不以事件类型推断应用协议；原始 EVE 保持不变。

条件包括最近 24 小时／7 天／30 天、记录类型、源／目的 IP、应用或传输协议、HTTP 方法、路径前缀、探针及流标识。接口另外支持注册代次和来源代次条件：注册代次要求同时指定探针，来源代次要求同时指定探针及注册代次。流标识采用规范的 uint64 十进制字符串，禁止指数、负数、前导零或超限值。

高级过滤使用服务端字段目录和受限 Wireshark 风格语法，仅作用于现有映射。`event.original` 保留原文但不参与分词；TLS、DNS、会话计数等详情字段从原文提取用于展示，不声称可以筛选这些尚未映射的字段。规则名称和严重级别属于告警条件，不作为流量条件。

每次查询最多 31 天、每页最多 100 条，列表最多浏览前 10,000 条。分页保持原查询窗口；刷新或重新检索重新确定窗口。该接口尚未使用 PIT 冻结跨页快照，期间写入或留存删除可能改变后续页的位置，不能把多个分页拼接结果当作完整取证导出。

## 详情语义

| 字段 | 展示含义与边界 |
| --- | --- |
| 事件时间 | EVE 源记录的时间；与采集器观察时间和平台接收时间分别展示，不解释为出站时间。 |
| 会话开始／结束 | 实际 `flow.start`、`flow.end`；缺失显示“未获取”，非法或倒置时间使派生详情不可用。 |
| 双向字节／包数 | 引擎客户端到服务端、服务端到客户端计数；保留 uint64 字符串精度，零与缺测分开，容量自动按 B／KB／MB／GB／TB 等转换。 |
| IP／MAC | 原事件单值地址与会话 `src_macs`／`dest_macs` 集合分开；集合不伪装成每个报文的 MAC，IPv6 与端口使用方括号。 |
| 流与来源身份 | 流标识、探针、注册代次和来源代次共同提供调查线索；流标识不能单独证明跨探针或跨代次为同一连接。 |
| TLS | 实际存在的 SNI、协议版本及证书字段；不推断密文已解密，日志配置、ECH、恢复会话和捕获缺口可能造成缺失。 |
| DNS | 日志格式版本、类型、应答码与实际查询数组；不把旧版顶层名称冒充新版查询，不补造解析答案。 |
| 原始 EVE | 保存的事件 JSON，管理员可读；不是原生通信报文、PCAP 或完整会话导出。 |

上述客户端／服务端、会话时间、MAC 集合及 DNS 格式语义遵循 [Suricata 8.0.7 EVE 格式文档](https://docs.suricata.io/en/suricata-8.0.7/output/eve/eve-json-format.html)。方向字段不等于企业网段的入站／出站；网段边界识别需要独立关联实现。

展示解析限定单条原文 128 KiB、每侧最多 16 个 MAC、最多 32 条 DNS 查询，并限制各文本长度。控制字符、过长内容、非法 MAC 或未知 DNS 版本显示受限状态；无效 JSON、时间或计数使详情不可用，不改写源事件。缺失的双向值不以零代替。

## 完整性与性能边界

查询禁止部分分片结果，要求实际超时标志、完整分片回执和精确总数；每页命中数、事件身份、所属日期分区、租户、类型、时间范围及页内唯一性均须一致。依赖中断、近似计数、少行或混入其他来源返回失败，不能显示为正常空列表。服务器调用最长 8 秒，ES 查询预算 5 秒，客户端切换条件或关闭页面取消旧请求，迟到响应不覆盖当前数据。

请求和展示均有界，不加载全量 EVE 到浏览器。现有索引仍使用明确类型：IP、keyword、date_nanos 和 HTTP wildcard 路径，避免用通用分词代替精确网络条件。独立原包捕获、分帧 Zstandard 归档、原字节下载和有界多切片会话导出已有实际链路，见 [PCAP 留存与会话完整性设计](PCAP留存与会话完整性设计.md)；协议事件列表与原包归档为独立视图。完整逐包分析、长连接及分卷重组、应用品牌识别、TLS 解密和海量数据容量仍未通过完整验收。

## 验收范围

单元测试覆盖详情提取、uint64 边界、查询来源约束和失败回执。独立 PostgreSQL／Elasticsearch 集成测试核对租户隔离、只读角色和真实空结果；原生链路用例读取实际 Suricata HTTP 事务和 flow 记录，核对同一流的告警、会话时间及双向计数。前端测试核对筛选、分页、详情、缺测、错误、取消和卸载。是否已通过当前源码的远程全量门禁，以[测试覆盖与验收记录](测试覆盖与验收记录.md)为准。

## 服务身份查询

协议数据集的字段目录与表达式编译器使用相同契约，告警专属字段及其别名不能在协议表达式中使用。外部 Agent 通过独立 `traffic:read` 权限调用 `traffic.search`、`traffic.fields` 和 `traffic.filter.validate`，复用相同时间、分页、来源、租户与完整性校验；返回经授权的元数据，不返回原始 EVE、原包或探针注册标识。具体接口与统计边界见[MCP 服务接入](MCP服务接入.md)。
