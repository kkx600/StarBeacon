# 星烽 StarBeacon 响应动作与执行追溯

“响应中心 → 响应动作”集中检索本租户的限时封禁、原租约回读和条件解除。此入口复用签名任务、采集器执行和设备独立回读协议，不提供 EDR 隔离、跨设备撤销或绕过原授权的直接设备操作。

## 检索与分页

页面默认固定最近 24 小时的创建时间窗口，时间输入按浏览器本地时区显示，接口使用绝对时间。开始时刻包含、结束时刻不包含；单次窗口最多 31 天，可查询留存期内的历史窗口。刷新读取同一窗口和当前任务状态，重置恢复最近 24 小时。

支持执行探针标识、联动设备标识、规范单个 IPv4／IPv6、动作类型及执行状态的精确筛选。界面每页 20 项，接口允许 1–100 项；按创建时间、任务标识倒序续页，不受通用任务目录最近 200 项上限影响。游标绑定全部筛选条件及页大小，变更筛选重新从第一页读取。不计算全量总数，不使用 OFFSET 扫描，当前页数量不代表全租户数量。

分页固定创建窗口，执行状态仍随设备回执变化，不提供数据库历史状态快照；状态变化可能影响后续筛选结果，重新核对时返回第一页。已过记录保留期限的任务不可读取，默认期限为创建时冻结的 `operations` 180 天策略，支持已有分类配置。执行截止、设备租约到期和记录保留截止分别展示。

查询只扫描响应任务，复用租户／创建时间索引及既有联动日预算。数据库语句限时 4 秒、存储上下文限时 6 秒；依赖、来源或游标不完整明确失败，不以空页掩盖错误。这些预算不构成生产容量或延迟承诺。

## 详情与操作

详情按主键独立读取，不依赖当前列表、设备在线、当前配置或当前平台签名密钥。读取核对原授权字节摘要、租户、执行探针、注册代次、任务类型和绝对期限；普通诊断／规则任务不属于响应目录。

详情分别展示平台执行状态、原设备／连接器、原租约、目标、期限、依据和已有配置回读。回读及解除任务可跳回原封禁任务。缺失回执保持待核对，不把平台受理、执行成功、回读时有效或后来到期推定为实际网络阻断效果。读取只计算未投递任务的到期显示，不修改任务、原回执或设备配置。

新的回读或解除仍核对当前探针、注册身份、能力、设备配置与保护范围，再提交独立签名任务。解除需要确认，只解除原任务的独立租约，不按 IP 全局删除。受理后响应中心打开新任务详情，即使当前固定窗口或类型筛选不包含新任务，也能独立核对回执。

## 未知提交

写请求之前保存本次请求键及完整输入。网络中断、服务端未知错误或回执缺失时，页面显示“联动提交结果尚未确认”，通过“核对原联动提交”发送原键、原输入，不能重新选择配置或生成新键。

确认原提交不先用设备的新配置替换原输入；设备后来离线或目录变化仍可由平台核对已经受理的原请求。平台继续复核当前账号资格，同键同输入只返回原任务，不补发、不续期。明确未受理的业务拒绝清除尝试，新的操作重新核对当前设备。

确认材料仅保存在当前页面会话中。离开页面、刷新、切换账号或撤回权限后，通过任务档案核对，不声称浏览器具有跨会话持久恢复凭据。此机制不替代全平台紧急停止、跨设备互斥或生产故障接管。

## 接口与权限

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/response-actions` | 固定窗口、精确筛选、绑定游标和独立观察时间；要求 `start`、`end` |
| `GET /api/v1/response-actions/{id}` | 指定响应任务；不接受查询参数 |
| `POST /api/v1/sensors/{id}/response-tasks` | 沿用既有封禁、回读及解除协议、CSRF 和请求键 |

列表和详情要求当前有效的本租户管理员。数据库事务重新核对租户、账号启用状态、角色和凭据修订，与账号管理共享锁；查询受租户 RLS 约束。跨租户、普通任务、已删除和到期档案统一返回不可访问，不输出连接器凭据、管理地址或完整签名命令。

浏览器核对筛选回显、每行原任务、纳秒排序和续页摘要，关闭、切换身份或卸载后取消请求，忽略迟到结果。主控与原型共用筛选表单、列表、详情和操作组件；原型明确使用合成数据，不调用平台或设备接口。

验证入口：`internal/response/catalog_test.go`、`internal/platform/response_catalog_test.go`、`tests/integration/response_catalog_test.go`、`web/tests/response-catalog.test.ts`。真实执行、覆盖率和部署资格只以[测试覆盖与验收记录](测试覆盖与验收记录.md)中的同源独立结果为准；完整响应需求仍有真实设备、EDR、冲突处理和应急控制缺口。
