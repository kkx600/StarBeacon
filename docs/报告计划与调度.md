# 星烽 StarBeacon 报告计划与调度

报告中心包含报告记录和报告计划两个独立视图。管理员可以创建安全日报、周报、月报计划，配置名称、IANA 时区、执行时间和智能总结模型，并在运行记录查看周期、错过范围、处理结果及报告详情。每个视图只显示一个业务表格；配置和报告详情采用弹窗。

## 日历与恢复

| 类型 | 计划执行日 | 统计范围 |
| --- | --- | --- |
| 安全日报 | 每个自然日 | 所选时区的上一个完整自然日 |
| 安全周报 | 每周一 | 所选时区的上一个完整周，周一开始 |
| 安全月报 | 每月一日 | 所选时区的上一个完整自然月 |

执行时间精确到分钟。使用所选时区的自然日历，不能用固定 24 小时推算日报或用 30 天推算月报。夏令时回拨造成同一分钟出现两次时，只选择第一次；时钟跳进缺失该分钟时，选择当日之后第一个有效分钟。整日被时区调整跳过时，该日不创建槽位。单元测试包含上述边界。

每次配置和后继槽位都通过 PostgreSQL 事务写入普通 River 持久作业。执行器重启后从数据库恢复；不依赖进程内定时器或内存型周期任务。配置保存失败时，计划和队列变更一并撤销。

默认恢复策略为生成最近一个完整周期，不逐周期补齐全部停机历史，避免恢复时集中调用模型。运行记录保存原到期槽位、实际采用槽位和错过范围；错过范围含起点、不含终点。它表示没有按这些计划槽位提交报告，不推断传感器覆盖、迟到事件水位或告警丢失。生成后到达的事件不会改写冻结快照。迟到补偿和人工历史补齐仍使用独立业务流程。

## 模型与资格

计划默认生成统计报告，不调用模型。智能总结必须指定可用模型及其准确修订，并明确勾选持续统计调用授权；授权只适用于该计划修订。配置表单再次编辑或模型修订变化后，需要重新确认。模型收到有界租户统计和来源标识，不收到原始通信包、载荷、凭据或其他创建人的对话。

执行时核对当前计划修订、启用状态、创建人当前管理员资格、模型修订、启用状态和期限。没有资格时记录静态业务原因，不能退回未授权的新模型或自动恢复过期授权。模型分析和连接验证共用 UTC 日额度及跨实例并发控制，不另建可绕过预算的调度通道。

创建人或租户停用、创建人降权后，首次到期和准备阶段恢复均保留失败周期，原子停止计划及后继任务，并记录系统操作审计。恢复账号后仍需手动启用计划并重新确认持续授权。统计读取前和报告提交时再次核对资格；数据库读取故障只重试准备，不把暂时不可用误判为权限撤销。模型额度不足不会停用其他未来周期。

统计准备失败可以在准备租约期限内有界重试。准备成功后，报告、分析作业、审计和运行关联在同一事务提交；同一周期不能重复创建收费调用。模型调用沿用分析作业的未知结果和不自动重复提交规则。统计报告可直接完成，模型失败时仍可复核冻结来源。

## 配置与运行状态

每租户最多 32 个计划，每 UTC 日最多 1000 次实际配置变更。计划及运行记录按租户和创建人隔离。配置通过预期修订比较更新；相同标识、原修订和完整参数的精确重试返回原保存结果，不增加队列或审计。连接中断或响应不完整时，界面冻结原请求，先确认该请求结果再允许继续编辑。

停用事务取消尚未执行的后继槽位，执行阶段再次校验修订。已提交的报告继续处理，界面不会把计划停用描述为分析已取消。报告取消需从独立报告结果入口操作，已送达模型的请求不能保证停止计费。配置保留在活动配置库，当前尚无计划删除入口。

| 运行状态 | 业务含义 |
| --- | --- |
| 准备统计 | 作业已取得本周期准备资格，尚未提交报告 |
| 已提交 | 已建立报告关联，具体状态取自报告作业 |
| 本周期未提交 | 准备或资格失败，可查看静态原因 |
| 报告已到保留期限 | 运行记录仍在，但关联报告不再对查询提供 |

“启用”和“下次计划时间”表示配置状态和调度目标，不保证在该时刻完成统计、模型返回或通知送达。页面刷新失败不把已有数据改为零；查看报告可以刷新结果。

## 留存与验收

运行记录使用创建时固化的报告留存期限，默认 180 天，可由分类留存策略调整未来记录。回收先删除已过期且不再活动的运行关联，再清理报告；引用的模型版本和当前计划配置受到保护。启用计划与历史记录采用不同生命周期。

`internal/assistant/plans_test.go` 验证日历边界；真实依赖测试入口为 `TestReportPlansDurableCalendarRecoveryOwnershipAndModelBudget`、`TestReportPlanLeaseQualificationAtomicSubmissionAndQuotas` 和 `TestReportPlanOwnerRevocationStopsInitialAndRecoveredRuns`，覆盖持久恢复、事务故障、隔离、首次到期和准备恢复的权限撤销、模型额度和到期引用。前端测试位于 `web/tests/report-plans.test.ts`。远程执行状态、源码身份与原始证据统一见[测试覆盖与验收记录](测试覆盖与验收记录.md)。受控模型协议测试不能替代真实模型效果或真实办公渠道送达验收。审批、正式发布、PDF 与通知分发尚未交付。
