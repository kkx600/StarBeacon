# StarBeacon v0.1.0-rc.3

本版本为工程预览版，用于隔离环境的安装、交互体验与已有功能验证；尚未达到完整产品和生产环境的正式验收要求。

## 界面与原型

- 主控平台、采集器及交互原型共用组件主题。按钮采用明亮蓝色，输入框使用浅灰轮廓；白色面板与浅灰工作区背景保持一致。
- 决策策略表单按业务含义分组，长表单内部滚动，弹窗标题与底部操作区固定。
- 800 张真实浏览器原型截图与当前主题对齐，159 项响应式布局观察通过。

## 检查范围

发布前要求同一提交的 GitHub 工程检查通过，包括 Go 构建、测试、静态检查、Linux 交叉编译，前端测试、类型检查、四项至少 90% 的覆盖门槛、生产构建，以及原型覆盖、主题与截图完整性校验。原型和自动化测试不代表真实外部产品、海量数据或完整生产部署验收。

## 安装包

仅提供 Linux amd64：主控平台和采集器各一个 ZIP。Go 程序使用 UPX 压缩，包内包含对应前端、配置示例、实际版本信息、项目与依赖许可及 SBOM；不包含运行凭据。发布页附带 SHA-256 清单。

ZIP 不是一键安装的完整运行环境。需自行配置 PostgreSQL、Elasticsearch、Redis、NATS、对象存储、Suricata、TLS 及身份凭据；具体要求见同一版本的[工程实现与开发](../工程实现与开发.md)。

## 验收边界

完整需求仍存在缺口，详见[功能实现与验收状态](../功能实现与验收状态.md)。生产 TLS／HA、备份恢复、1–200+ 探针容量、真实防火墙／EDR 阻断效果、外部办公渠道、模型效果和沙箱等尚未完整验收。本次发行不表示远程业务环境已升级，不声明全界面达到 WCAG AA。

工程预览由独立的 `preview.yml` 发布，仅接受 `-rc.N` 版本并标为 GitHub Prerelease，不占用稳定版 Latest。正式发布仍使用 `release.yml`，要求同一提交的完整功能、覆盖率、远程生产部署与实际压缩包验收。
