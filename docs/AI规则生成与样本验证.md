# AI 规则生成与样本验证

## 使用流程

管理员在“规则管理 → AI 规则生成”填写检测说明，选择自然语言、PCAP 或 HTTP Raw 材料，以及已启用的模型配置修订。确认本次材料可以发送至所选模型后，提交 1–3 条候选规则生成任务。

PCAP 与 HTTP Raw 使用“重放样本”中当前租户、未过期的对象。HTTP Raw 先按文件原始字节导入；自然语言任务不附带样本或帧引用。生成任务记录模型修订、材料摘要、模板、分配的 SID、状态、提供方返回用量和候选规则。

成功候选可人工采纳为规则包修订 1。采纳保留原始正文、摘要和生成来源，重复操作返回同一初始修订，不覆盖后续人工修订。随后按照既有流程完成目标探针原生装载检查、独立正反样本回放、配置摘要核对，再申请规则发布。模型生成、规则包保存、原生测试通过和探针实际生效是不同状态。

## 材料与事实边界

平台从对象存储完整读取所选样本，核对长度和 SHA-256 后，使用 GoPacket 进行有界容器及数据包检查。原始对象保持不变。模型只接收首 128 帧内最多 8 段 TCP / UDP 载荷，每段最多 256 字节，以及文件时间、MAC、截断和 TCP 握手观测摘要。帧引用使用原文件序号。

摘要提取不进行流重组、TLS 解密、HTTP 规范化或攻击结果判断。超出截取范围、分片、无法解析的帧会形成材料限制；没有载荷或材料受限不等于流量安全。加密材料不能作为未经观测的明文事实来源。生成提示将材料视为非可信数据，不授权工具调用、脚本、外部文件读取或设备动作。

HTTP Raw 按原字节封装为 Ethernet / IPv4 / TCP PCAP，保留 CRLF、重复字段、二进制内容及原有协议错误，不自动修复请求。每段载荷最多 1,460 字节，包含合成 SYN、SYN-ACK、ACK 和连接关闭序列；不补造 HTTP 响应，不向网络发包。地址来自文档地址段，MAC 和包时间均为合成。`origin` 保存原始请求摘要、字节数和 `http-raw-tcp/1` 编码标识；PCAP 摘要单独保存。合成握手不能证明真实捕获或服务器通信。

## 输出与规则身份

模型通过已配置的 Responses API 或 Chat Completions API 严格 JSON Schema 生成候选，使用官方 Go SDK，不自动降级为非结构化输出。单次最多 3 条候选；每条规则为单行 `alert`，UTF-8 正文不超过 16 KiB，包含唯一已分配 SID、`rev:1` 和非空 `msg`。

服务器拒绝重复 JSON 键、额外字段、未知 SID、重复候选、错误引擎版本、无来源帧引用，以及脚本、动态外部数据集或执行动作。模型不能指定规则包身份或摘要。通过这些约束仍不代表 Suricata 原生语法或检测效果通过；原生检查由实际目标探针执行。

租户保留 SID 范围为 **1,000,000–1,999,999**，分配前登记已有规则占用。SID 注册与生成任务、队列及审计在同一事务中提交。范围内人工规则不能占用其他包或候选的 SID；同一个规则包的人工修订可以沿用自身标识。已登记 SID 不因历史到期而分配给其他规则，避免历史告警身份混淆。保留区耗尽返回明确冲突，不进行 SID 循环复用。

`generation_id` 与 `generation_sid` 描述规则包的创建来源。后续人工修订继承创建来源，但只有初始采纳修订与原始候选正文精确一致。

## 额度、取消与故障

生成任务与连接测试、智能助手和模型报告共享提供方的每日额度及并发预算：每个提供方最多 1 个活跃调用、每个租户最多 4 个；规则生成额外限制每租户每日最多 1,000 个作业。额度包括已预留任务，不能按仅成功响应计算。材料准备每个 API 实例最多并发 2 个请求，最长 12 秒；HTTP Raw 上限 2 MiB，PCAP / PCAPNG 上限 100 MiB。

请求使用所有者范围内的幂等键，冻结输入、模型修订和材料。相同键、相同输入返回同一任务；改变输入返回冲突。浏览器提交结果未知时保留原请求，确认操作继续使用原键，不创建第二个生成任务。

创建与实际执行分别检查所有者管理员权限、当前模型修订、启用状态、凭据和样本期限。排队取消不调用模型；执行中取消向任务队列和请求上下文发出取消信号，但不保证提供方停止处理或计费。

模型请求仅执行一次，不自动重试。已可能发送的调用发生超时、断连或结果落库失败时，任务保留未知状态，运行租约超时恢复为 `uncertain`，禁止任务救援重复调用模型。数据库连接中断应回滚 SID、队列、候选及审计变更；不能把部分落库当作成功。

## 存储与接口

样本按 PCAP 保留策略存储，生成历史按模型保留策略存储，默认均为 180 天，可由管理员配置。活跃任务的样本和模型版本不能在执行中删除；仍被现有规则包引用的创建来源保留以支持追溯。SID 注册属于当前规则命名空间，不作为到期历史清理。

| 入口 | 操作 |
| --- | --- |
| `POST /api/v1/replay/samples/http` | 平台导入 HTTP Raw |
| `POST /api/local/v1/replay/samples/http` | 采集器导入 HTTP Raw |
| `POST /api/v1/rule-generation/jobs` | 提交持久生成任务 |
| `GET /api/v1/rule-generation/jobs` | 当前所有者历史，每页 20 条 |
| `GET /api/v1/rule-generation/jobs/{id}` | 材料、候选及处理结果 |
| `POST /api/v1/rule-generation/jobs/{id}/cancel` | 取消请求 |
| `POST /api/v1/rule-generation/jobs/{id}/adopt` | 人工采纳指定 SID |

所有入口要求管理员权限；平台生成任务还限定租户与当前所有者。写操作要求同源会话及 CSRF。采集器仅提供离线样本导入和重放，模型生成在主控平台执行。

## 验收范围

单元测试核对材料完整性、字节保持、JSON 与规则约束、官方 SDK 的严格输出请求，以及前端状态、取消、未知结果和采纳交互。集成测试使用真实 PostgreSQL、River 队列、受控 HTTPS 模型协议服务与实际 Suricata 8.0.7；受控模型服务用于验证接口和调用次数，不代表外部模型效果评测。

远程验收必须分别完成平台和采集器的 HTTP Raw 导入、目标探针回放、正反样本检测、原生装载检查及任务回执核对。尚未通过同源码远程验收的功能不能因本地测试通过而取得发布资格。测试状态以[测试覆盖与验收记录](测试覆盖与验收记录.md)为准。
