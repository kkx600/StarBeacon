# 星烽 StarBeacon 依赖版本与部署清单

核定日期：2026-09-28。本文是项目固定选型基线；版本已核对官方来源，完整应用构建、集成与性能验收尚未进行。Go 按项目要求精确固定 1.26.0，PostgreSQL 使用 18 系列最新补丁；Redis、Elasticsearch 采用核定日官方最新正式稳定版。后续维护通过受控升级，不追随浮动 `latest`。

来源：[Ubuntu Server 镜像](https://releases.ubuntu.com/24.04/)、[Docker Engine 发布说明](https://docs.docker.com/engine/release-notes/29/)、[Compose 5.5.1](https://github.com/docker/compose/releases/tag/v5.5.1)、[Docker 官方 APT 仓库](https://download.docker.com/linux/ubuntu/dists/noble/pool/stable/amd64/)。APT 与 Docker 静态二进制自带的底层组件可能不同，必须使用一种固定分发方式，不拼接两种安装说明。

默认平台自身提供 HTTPS 静态页面／API，gRPC 独立监听，或接企业已有 L4/L7 入口；因此 Nginx、Ingress、API 网关不是强制依赖。Kubernetes、Helm、服务网格、Kafka、ClickHouse、向量库、图数据库、Temporal、独立 SOAR 均不进入首期必装清单。未来因瓶颈引入时单列 ADR、版本、成本和迁移验证。

标准 PG 主备可以采用明确 fencing 的受控人工切换或企业现有托管 HA；若交付要求自动数据库故障转移，必须另选并锁定受支持的 HA 组件，不将“主备已建好”当成自动切换已实现。密钥默认来自受控挂载及信封加密，可接现有 KMS；OIDC、SMTP、设备 API、外部 Syslog 是客户服务依赖，需要端点、证书、账户权限与契约验收，不为它们虚构统一软件版本。

## 6. 拓扑、端口与资源隔离

| 连接 | 建议端口／方向 | 网络边界 |
| --- | --- | --- |
| 用户／Agent → 平台 | HTTPS 443，含 MCP／SSE | 公开或客户内网入口，统一身份及限流 |
| 探针／Runner → 平台 | mTLS gRPC 7443，可经已有代理汇聚 | 主动出站，按证书及租户注册授权 |
| 服务 → PG | 5432 | 仅业务／备份网段，非公网 |
| 服务 → ES | HTTPS 9200；集群内部 9300 | 外部用户不直接访问 ES |
| 服务 → Redis | 6379；Sentinel 26379 | TLS/ACL，按环境配置端口，非公网 |
| 服务 → NATS | 4222；集群路由 6222；监控 8222 | mTLS、subject 权限，监控仅运维网络 |
| 服务／探针 → S3 | HTTPS 443 或配置的 API 9000 | 管理控制台独立且不公开给普通租户 |
| 运维 → 指标 | Prometheus 9090、可选 Grafana 3000 | 单独运维身份；探针健康经平台汇聚 |
| 平台／Runner → Syslog | TLS 6514；兼容 TCP/UDP 514 | 客户配置目标，明确确认语义 |
| 通知／模型出站 | HTTPS 443；邮件 587/465 按服务商 | 允许列表、限流、证书和密钥轮换 |

端口是部署起点，可因企业标准调整；内网端口表不代表应向互联网开放。抓包、浏览器、规则回放、模型推理、实时索引各有独立资源上限。报告浏览器和设备认证浏览器不得共享登录上下文。

## 7. 固定版本后的验收与升级

1. 工程形成后固定 `go.mod/go.sum`、`pnpm-lock.yaml`、生成器清单、容器 tag 与各架构 digest、OS 包清单及 SBOM；当前方案阶段尚无这些实际构建产物。
2. 用 Go 1.26.0 进行目标 Linux 架构完整构建，执行 Proto 兼容和关键契约测试；前端执行冻结安装、vue-tsc、生产构建与关键操作验证。
3. 验证 ES 9.5.4 映射／分析器、PG 18.6 RLS／迁移、Redis 故障退化、JetStream 严格持久化和重放；服务版本一致不等于配置已正确。
4. 模型、规则、连接器分别执行自己的兼容与回滚验收；同一浏览器版本也不能证明所有设备控制台可自动登录。
5. 用真实 EPS、包速、载荷、规则集、查询并发、保留期和故障场景验证三档部署。性能数据写入独立基准报告，未测试前不填写吞吐实测值。
6. 升级先在兼容矩阵中试验，再灰度。Go 版本保持用户指定值，除非后续明确调整；数据迁移和应用回滚分开，ES 不依赖直接降级二进制恢复旧数据。

许可证登记区分组件源码、发行二进制和可选商业功能。Redis 8 不是旧 BSD 许可，ES 默认发行物与部分源码许可不同，MinIO HA 需许可，Grafana OSS 有对应开源条件；选定交付方式后保留实际条款与第三方通知，不能将上述组合统一标成“全部 Apache／免费商用”。详情与官方链接见[依赖版本核验](research/依赖版本核验.md)和[采集链路与存储调研](research/采集链路与存储调研.md)。
