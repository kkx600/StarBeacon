# 告警模型研判

## 使用流程

管理员在“告警中心 → 告警详情 → 模型研判”选择模型及其当前修订，填写可选的业务说明，并确认本次材料可发送给选定模型。平台创建持久作业，保存冻结材料、模型修订、模板及输入摘要；当前管理员可查看自己的研判历史、结果和调用用量。

结果展示模型建议结论、攻击尝试或结果未知、判断依据、事实引用、反证、待补充信息与处置建议。模型自评分明确标为未经校准的自报分数，不等同于攻击成功概率。模型建议不会修改人工研判，也不会直接抑制告警、发布规则或执行设备封禁。

人工研判与模型研判位于同一告警详情的不同页签。研判历史通过选择器分页查看，每页 20 条，页面最多同时保留 100 条；结果和材料在当前页展示，避免多张业务表格并排出现。

## 材料与来源

平台按当前租户精确查询事件标识，要求跨索引仅有一个来源、原始 SHA-256 一致、分片完整且记录类型为告警。索引日期由平台路由分配，历史重放与延迟上报的事件时间可以早于索引日期，不因日期不同拒绝合法材料。

研判白名单最多 17 个实际字段：事件时间、探针及注册代次、源／目的 IP、传输／应用协议、规则标识／修订／名称、HTTP 方法／主机／路径、级别、流标识、引擎动作及证据状态。单个值最多 2,048 字符，材料最多 24 KiB，材料、用户说明及指令合计最多 24 KiB。异常格式字段不发送，超长字段截断并记录材料限制；合并输入超限时在创建作业前拒绝，不占用模型调用额度。

不发送原始 EVE、原始报文、完整会话、模型无须使用的租户信息或平台凭据。用户说明最多 2,000 字符，也属于不可信数据。作业实际调用前重新回读告警并核对冻结材料摘要，来源变化、过期或不可访问时停止调用。

规则命中、HTTP 状态码、TCP 握手和设备 `allowed` 不能单独证明入侵成功。本入口没有独立终端执行或业务结果证据，也不进行 TLS 解密；模型攻击结果仅允许“尚未确认”或“观察到攻击尝试”。

## 输出校验

使用官方 Go SDK 请求严格 JSON Schema，并在服务器独立核对字段、重复键、类型、长度、有限评分、枚举及事实引用。不接受额外执行指令、任意封禁目标、内部思维过程或无来源证据。

除“证据不足”外，结论必须引用材料中实际事实。误报建议必须讨论反证；源 IP 封禁建议必须具备确认威胁的建议结论、实际源 IP、引用及反证，仍然只是待复核建议。所有结果都要求 `needs_review=true`，并以 `confidence_kind=self_reported` 保存评分来源。

## 额度与故障

研判与连接测试、智能助手、模型报告及 AI 规则生成共享预算：每提供方最多 1 个活跃调用、每租户最多 4 个，每日额度按 UTC 计算且包含已预留任务。研判还限制每租户每日最多 1,000 个作业；材料准备每个 API 实例最多并发 2 个请求。

租户及当前管理员所有者限定历史与详情权限。创建和实际调用分别检查管理员执行资格、模型修订、启用状态和凭据。作业、队列和审计在同一事务中提交；模型调用仅执行一次，不因超时、断连或未知落库结果自动重试。

提交使用所有者范围内的幂等键；相同键与相同输入返回原作业，不同输入返回冲突。浏览器未知提交保留原键和输入，冻结表单与详情关闭，确认原请求后恢复操作。排队取消不会调用模型；执行中取消不保证提供方停止处理或计费。运行租约过期恢复为“结果未知”，需要核对提供方记录。

页面仅轮询活动作业，隐藏时暂停查询，连续错误按退避策略停止自动轮询并保留手动恢复入口。错配、缺失或迟到响应不能显示为成功；卸载页面终止在途浏览器请求。

## 存储与接口

研判历史按模型留存策略固化期限，默认 180 天，可自定义。运行中作业及仍引用的模型修订受到回收保护；人工研判历史另行保存。

| 接口 | 含义 |
| --- | --- |
| `POST /api/v1/alerts/{id}/triage` | 提交指定告警的模型研判 |
| `GET /api/v1/alerts/{id}/triage?sha256=…` | 当前所有者研判历史 |
| `GET /api/v1/alert-triage/jobs/{id}` | 冻结材料与执行结果 |
| `POST /api/v1/alert-triage/jobs/{id}/cancel` | 登记取消请求 |

写操作要求同源管理会话、管理员权限和 CSRF；提交要求 `Idempotency-Key`。完整契约见平台 OpenAPI。

## 验收边界

单元及交互测试验证证据限制、严格输出、实际引用、未知提交、取消、分页和视图生命周期。远程集成测试使用真实 PostgreSQL、Elasticsearch、River、Suricata 和受控 HTTPS 模型协议服务；协议服务可验证官方 SDK 请求、幂等次数与输出校验，不能代表外部模型的领域准确率。

自动触发策略、独立终端／业务证据补充、真实外部模型评测、概率校准与响应授权仍需对应实现和实测。不能凭模型自评分或这项单告警功能认定自动响应已交付。当前同源码测试结果见[测试覆盖与验收记录](测试覆盖与验收记录.md)。
