# 星烽 StarBeacon 探针分组与管理信息

探针管理通过同一工作区的「探针列表」「探针分组」「任务记录」组织部署目录。每个页签只展示一张业务列表；查看详情和编辑使用弹窗。管理员维护管理信息，只读账号查询目录、详情和分组成员。任务记录及任务操作仅对管理员开放。

## 管理对象

| 对象 | 字段与规则 |
| --- | --- |
| 探针管理信息 | 名称、所属分组、站点和说明；名称为 1～128 个 Unicode 字符，站点最多 128 个字符，说明最多 1000 个字符。文本必须为有效 UTF-8，不能含换行或控制字符。 |
| 探针身份 | 探针标识和注册代次只读；提交必须匹配当前注册代次，重新登记后的旧表单不能覆盖当前设备信息。 |
| 管理修订 | 独立于采集配置，初始为 1；提交携带预期修订，并发变更返回冲突。没有字段变更时不产生修订。 |
| 探针分组 | 名称、说明、启用状态、成员数量和管理修订；名称在当前租户内不区分大小写唯一，停用记录仍保留该名称。 |
| 分组成员 | 一台探针最多属于一个分组；空分组标识表示未分组。成员数量包含停用探针，已有成员的分组不能停用。 |
| 分组状态 | 创建时必须启用；停用后可恢复。探针只能归入当前租户的启用分组，停用前须逐台调整成员归属。 |

分组用于目录归类，不改变租户归属、采集范围、资产组或执行授权。编辑管理信息不启停探针，不修改证书、心跳、网卡、BPF、规则或任务。分组没有级联删除入口；当前有效配置不按创建时间自动清理。

## 目录与分页

探针目录按名称、标识或站点检索，支持所属分组、未分组和连接状态筛选。关键词按字面值匹配，百分号和下划线不能扩大检索范围。在线判定使用平台接收的最近心跳，超过 35 秒为离线；停用状态优先，历史健康值保留观察时间。

分组目录支持名称和启用状态筛选，成员链接返回探针列表并固定所选分组。默认每页 20 项，HTTP 接口允许 1～100 项，按标识稳定游标翻页；页面显示当前页数量，不把它标为全部设备数量。上一页、下一页、重置和刷新分别保留或清除对应筛选条件。连接失败和异常分页显示读取错误，不伪装为空目录。

重放、规则检查、规则发布、采集配置和规则核实的探针选择器逐页读取完整授权目录，避免只显示首屏设备。单次最多 10000 台，重复记录、无效或不前进的游标、过大页面、请求取消及未结束目录均阻止展示部分选项。分组选择器只包含启用分组，完整读取后才能提交归属变更；加载失败保留刷新入口，不隐式移出当前分组。

## 提交与一致性

| 环节 | 实际约束 |
| --- | --- |
| 权限 | HTTP 会话、CSRF 和管理员角色检查后，事务再次核对账号与租户当前状态；跨租户对象返回不可见结果。 |
| 请求身份 | 每次操作携带幂等键，绑定租户、操作者、操作类型、对象与完整输入。不同输入不能复用旧键。 |
| 原子保存 | 管理对象、操作审计和公开回执在同一 PostgreSQL 事务提交；故障中断不会留下部分变更。 |
| 并发 | 分组管理按租户串行核验，账号权限与身份维护共享事务锁；管理修订和探针注册代次在写入时再次核对。 |
| 结果未知 | 客户端 30 秒未取得可核验回执时冻结原输入与请求键，明确显示尚未确认。关闭弹窗后可恢复同一草稿并主动核对，不自动创建另一次操作。 |
| 留存 | 管理回执和操作审计默认保留 180 天；回执采用操作日志类别的自定义期限，仅影响后续提交。仍存在的到期回执拒绝重放，维护任务只删除到期历史。 |
| 额度 | 当前租户最多 512 个分组，包含停用记录；管理提交额度为滚动 24 小时 10000 个首次成功请求。原请求确认不重复计数或审计。 |
| 数据库授权 | 运行账号可读写分组、插入和查询回执、按到期策略清理回执；不能更新回执、删除分组、直接改写用户或登记探针身份。 |

事务回执冻结的是该次提交结果，之后发生变更时仍返回原回执；页面再刷新当前目录。重新登录、账号或租户切换以及页面卸载会清除未确认输入，不能把另一身份的草稿带入当前会话。

## 当前接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/sensors` | 当前租户的分页探针目录；`cursor`、`keyword`、`group_id`、`status`、`limit`。 |
| `GET /api/v1/sensor-groups` | 分页分组目录；`cursor`、`keyword`、`active`、`limit`。 |
| `POST /api/v1/sensor-groups` | 创建或修改分组，携带 `id`、`expected_revision`、`name`、`description`、`active`。 |
| `PUT /api/v1/sensors/{id}/metadata` | 修改探针管理信息，携带预期管理修订、注册代次及全部管理字段。 |
| `PATCH /api/v1/sensors/{id}` | 独立维护既有探针启用状态，不作为管理信息编辑接口。 |

分页响应包含 `items` 和 `next_cursor`，空游标表示该次查询已结束。不接受重复参数、未知参数或与目录类型不适用的筛选。字段和响应以[平台 OpenAPI](../api/openapi/platform.json)为准。

## 验证与范围

单元测试核对文本、修订、分页和回执边界；真实集成用例覆盖 PostgreSQL 最小权限与租户隔离、HTTP 登录和 CSRF、501 台探针完整分页、管理并发、断线回滚、分组额度和历史清理。Vue 测试覆盖单表页签、成员跳转、完整选择器、只读操作、错误焦点、原请求确认与取消。

当前执行状态统一记录在[测试覆盖与验收记录](测试覆盖与验收记录.md)。测试存在不等于该源码已完成远程全量验收；探针升级、证书轮换编排、自动规则订阅、设备联动和集团委派仍按[功能实现与验收状态](功能实现与验收状态.md)登记独立缺口。
