# 星烽 StarBeacon 告警研判与协作

## 功能与事实边界

管理员从告警详情进入「告警研判」，填写处理状态、研判结论、攻击结果、说明和证据引用，可将告警认领给当前账号。同租户管理员共享当前研判及修订历史；只读账号不能访问研判操作。认领表示协作责任，不限制其他管理员复核。该功能不执行规则抑制、告警删除、通知撤回、模型判断或设备封禁。

原始事件仍由 Elasticsearch 保存和检索。PostgreSQL 仅保存工作流元数据、原始摘要、操作人、认领人和依据，不复制 EVE 或通信载荷。每次读取与保存都先核对当前租户下唯一的原始告警；原始摘要不符、重复事件身份、分片失败、查询超时或依赖不可用时停止操作。

## 状态和结论

| 字段 | 选项 | 约束 |
| --- | --- | --- |
| 处理状态 | 待处理、调查中、已关闭 | 关闭必须已有误报或确认威胁结论；可以重新打开调查 |
| 研判结论 | 未研判、待核实、误报、确认威胁 | 结论为人工输入，不表示模型或引擎已验证其正确性 |
| 攻击结果 | 未确认、攻击尝试、攻击成功、已阻止 | 只有确认威胁允许记录后三项；成功或已阻止必须提供可复核证据引用 |
| 研判说明 | 1–2048 个 Unicode 字符 | 必填；不接受空白正文、非法编码或控制字符，允许换行和制表符 |
| 证据引用 | 最多 8 条，每条 1–256 个字符 | 每行一条，不重复；填写案件、终端或设备回执标识，不填写密码或令牌 |
| 认领 | 当前账号 | 明确提示会替换已有认领人；未勾选时保持原认领 |

攻击尝试不等于攻击成功。「已阻止」应来自独立设备或终端证据；网络旁路告警、连接中断和没有后续流量均不足以自动得出该结论。引用目前是人工记录的标识，不会自动获取或校验外部案件、EDR 或防火墙回执。

## 保存、并发与未知结果

保存要求 CSRF、规范的 `Idempotency-Key`、选中告警的 `raw_sha256` 和 `expected_revision`。服务端在租户事务锁下核对当前管理员资格、输入摘要与修订，原子写入当前研判、不可改写历史和操作审计。任何一项写入失败都回滚。过时修订和同键不同输入返回 `409`，不覆盖其他管理员的结论。

相同账号、告警、请求键和完整输入的精确重试返回原保存结果。即使其他人随后完成新的修订，原请求也只回读旧结果；用户需刷新查看当前版本。网络中断、服务端故障或响应不完整时，页面保留原输入及请求键，禁止更改或关闭详情，提供「确认保存结果」。不会自动创建另一次保存。

每租户 UTC 自然日最多 10,000 次实际变更，每告警最多 1,000 次修订。原请求精确重试不消耗额度。达到单告警上限后，短时间重试不能解除该上限。历史按修订倒序分页，每页最多 20 条，翻页使用上一页最后的修订号，不按时间偏移。

## 留存与权限

每次保存按当时的告警分类策略固化到期时间，默认 180 天；修改策略仅影响后续操作。当前研判的到期时间跟随最后一次保存，历史每条独立到期，操作审计采用自身分类期限。账号或租户撤销后，旧身份不能继续保存。

运行角色没有研判历史 `UPDATE` 权限，数据库强制租户 RLS；删除只能作用于到期历史。当前研判还要求关联历史已全部回收。清理沿用有界分类轮转和租户锁，不扩大在线角色对用户、租户或未到期事实的权限。

已过期但物理行尚未回收的当前研判及原请求结果返回 `410 assessment_expired`，不会显示成从未处理，也不允许续写。历史列表只返回有效记录。全部研判记录回收后，若原始告警仍在，其初始研判为未研判；请求键及旧修订不跨保留周期存续。此时不再提供旧记录的幂等回读。

## 页面与接口

详情中的「通信证据」和「告警研判」采用页签。「查看研判记录」切换到单张历史列表，返回后刷新当前版本。错误与无记录分开显示，读取失败保留上次记录并禁用保存。表单在窄屏纵向排列，长说明和标识换行，历史表在自身容器中横向滚动。

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/alerts/{id}/assessment?sha256=…` | 读取当前研判，初始版本为 0 |
| `POST /api/v1/alerts/{id}/assessment?sha256=…` | 保存人工研判，返回本次实际保存结果 |
| `GET /api/v1/alerts/{id}/assessment/history?sha256=…&before=…` | 读取有效修订历史 |

错误区分输入无效 `400`、无权限 `403`、原始告警不存在 `404`、来源或修订冲突 `409`、研判过期 `410`、额度不足 `429` 和依赖不可用 `503`。完整契约见[平台 OpenAPI](../api/openapi/platform.json)。
