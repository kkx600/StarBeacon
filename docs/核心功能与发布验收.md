当前源码提供采集器通用 HTTPS 连接器、签名限时封禁任务、独立租约回读、条件解除、固定到期、管理地址保护和默认 180 天追溯；匹配研判可以人工独立确认，或依据已显式配置的持续策略核对固定条件并生成独立限时授权；自动模式不能再通过人工入口授权。模型判断本身不授予设备执行权限。平台 110 个、采集器 17 个 HTTP 操作及 107 项需求已完成静态对齐。上一轮源码与双端前端的实际 ZIP、部署和页面证据仍按原来源读取；后续代码不继承历史验收资格。本阶段通用连接器的协议端点不阻断实际流量，具体设备效果另行验收。自动研判生产规模与故障恢复、完整 CRUD、生产容量及全产品验收仍未完成，不能正式发布。实现与协议见[HTTP 联动与限时封禁](HTTP联动与限时封禁.md)。
