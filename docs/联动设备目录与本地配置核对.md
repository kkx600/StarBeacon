# 联动设备目录与本地配置核对

主控平台的「响应中心 → 联动设备」读取采集器最近一次心跳中的 HTTP 连接器目录。管理地址、受信 CA 与 Bearer 文件仍由执行采集器的私有文件管理。目录不接收、托管或返回凭据，也不替代设备本身的配置管理。

## 目录和状态

管理员可按执行探针标识、设备标识、设备核验状态精确筛选。每页默认 20 项，接口允许 1–100 项，按探针、连接器标识升序读取；续页绑定全部筛选条件和页大小。每个探针最多登记 8 个连接器，不使用最近 200 项任务列表或一次性探针列表作为完整设备目录。

目录分别记录：

- 设备标识、连接器标识、接口版本、配置 SHA-256 和最长封禁期限。
- 执行探针、注册身份、平台接收心跳时间及探针本机观测时间。
- 原始设备核验状态，以及设备观测是否新鲜。
- 探针是否声明支持封禁、回读和解除三种任务。

设备观测超过 35 秒，或比平台读取时间超前超过 30 秒，显示为过期。尚未进行设备核验显示为等待核验。探针离线或停用后，目录保留最后上报的设备身份和观测，不能据此继续提交设备操作。页面还会随时间撤销过期观测的提交入口。

核验状态筛选针对最近一次上报的原始 `ready/unverified/unavailable`；它不等于当前执行条件。心跳、设备核验和读取时间分别展示。翻页期间心跳可能变化，目录不承诺跨页的状态快照；重新查询可以读取当前目录。选中页的设备来源无效或读取失败返回错误，不能伪装为正常空结果。

## 详情和任务关联

设备详情展示运行配置绑定与观测来源。限时封禁预检固定所选探针、注册身份、连接器、设备和配置摘要；不能自动换用其他设备。观测过期、注册或配置变化时，须刷新后重新核对。

任务受理后按原任务编号打开独立详情，不依赖列表的固定时间窗口；列表可以重置时间条件后重新读取。

实际提交沿用签名任务链：平台复核管理员权限、当前探针与配置，采集器复核本机授权目标、保护范围与到期时间。目录的“具备提交条件”只是页面预检状态，不保证授权或物理阻断已经发生。结果未知时保留原输入和请求键，核对原受理结果，不生成第二次封禁。

“相关动作”携带执行探针与设备标识，进入响应动作目录。默认检索最近一天，可自行调整至最多 31 天的窗口；它关联该探针、设备在不同配置下的历史动作，并非只查当前配置。设备离线不妨碍读取留存期内的原任务与独立回执。

## 采集器本地配置核对

采集器的「网络与采集 → 联动设备 → 核对本地配置」只读取启动时 `SB_RESPONSE_CONNECTORS_FILE` 指定的文件。接口为 `GET /api/local/v1/response-config-check`，需要本地管理员登录，不接受路径或其他查询参数。

| 状态 | 业务含义 |
| --- | --- |
| 未配置本地连接器 | 运行实例没有启用 HTTP 连接器服务 |
| 文件与运行配置一致 | 文件权限和结构有效，解析后的配置与启动时绑定一致 |
| 文件已变化，需重启生效 | 文件结构有效，但与运行实例绑定不同；尚未应用 |
| 文件无法读取或配置无效 | 文件缺失、权限不符或结构无效；保留原运行配置 |

检查不读取 CA 或 Bearer 内容，不测试设备网络或认证，不执行保存、热加载或设备操作。相同路径的 CA 内容变化不由文件摘要检测，须按部署流程重启采集器并核对设备健康；同路径 Bearer 文件可原子轮换，由后续设备请求重新读取。文件一致不能被解释为认证通过。

本机文件须为当前服务可读的普通私有文件，推荐权限 `0600`，不接受符号链接或 FIFO。每份文件最多 8 个连接器，默认追溯留存 180 天，可配置 1–3650 天。具体协议、目标保护和失败恢复边界见[HTTP 联动与限时封禁](HTTP联动与限时封禁.md)。

## 验证与交付边界

单元、接口、数据库隔离和页面测试覆盖筛选绑定、超过 200 项的分页、损坏来源、时效、账号撤回、配置漂移及请求取消。当前源码的实际远程验证与覆盖率以独立验收记录为准。

通用 HTTP 协议夹具不能替代商业设备验收。完整网络域管理、设备 HA、执行器排他接管、集中配置生命周期与浏览器认证插件仍需要独立实现和验收。
