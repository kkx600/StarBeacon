# 星烽 StarBeacon 决策策略与影子评估

决策策略用于验证已完成模型研判是否符合配置的判断条件。支持策略配置、不可变修订、语法检查、按需影子评估和独立结果档案；判断结果始终为 `execution_authorized=false`。持续模式可为当前维护者的新研判形成待确认候选，或通过[持续决策与自动授权](持续决策与自动授权.md)独立授权限时签名任务。匹配的源 IP 封禁候选也可由管理员通过[研判处置确认](研判处置确认.md)明确确认。判断本身不改变人工结论；自动发起模型研判、多级审批、场景校准和真实流量效果核验尚未交付。

## 操作入口

管理员在“模型配置 → 决策策略”页签维护策略。目录只显示一个策略表格；创建、编辑、详情和影子评估分别使用独立弹窗。筛选草稿在点击“检索”后生效，空结果与未配置状态分别说明业务含义；修订冲突和未知提交不能显示保存成功。

告警详情中的模型研判完成后，管理员可点击“评估决策策略”，带入本人研判作业标识。进入策略页不会自动评估；选择策略并确认执行后，页面先读取本人材料，再以策略当前修订评估。每次评估复用已有研判，不重复请求模型。模型仍在执行、记录过期或不可访问时，不产生处置授权。

“模型配置 → 评估记录”使用独立表格查看本人历史，可按策略标识、研判作业和判断状态筛选；详情弹窗展示判断依据、原策略快照与来源摘要。当前配置变化不重写历史结果，研判材料按其自身期限回收后档案仍按操作策略保留。

平台模型配置导航对管理员开放；只读 API 账号可读取本租户策略和校验定义，但不能修改或执行影子评估。研判材料仍按创建账号隔离，管理员身份不自动授予其他账号私有材料的访问权。

## 配置契约

| 字段 | 规则 |
| --- | --- |
| 策略名称、说明 | 名称 1–128 字符，说明最多 1000 字符；首尾空白和控制字符拒绝保存 |
| 标识、修订 | 标识使用规范小写 ID；创建期望修订为 0，编辑使用当前修订，最大可写期望修订 999999 |
| 状态 | 创建时启用；停用后保留配置和历史，可验证“不参与决策”状态 |
| 运行模式 | `shadow` 按需评估；`approval` 持续评估与独立人工确认；`automatic` 持续评估与限时自动授权；持续模式必须完整配置 `continuous` |
| 模型自报分数阈值 | 大于 0 且不超过 1，不表示经校准的攻击概率；判断由表达式决定，自动授权始终额外比较阈值且要求阈值至少 0.5 |
| 判断表达式 | CEL 布尔表达式，UTF-8 最多 2048 字节；未知变量、类型错误、非布尔结果和循环宏拒绝保存 |
| 候选处置 | `investigate`、`notify`、`block_source`；仅为建议标签，不发送通知或封禁 |
| 材料观测时限 | 60–86400 秒，按冻结材料 `observed_at` 核对；它表示平台观测时间，不是攻击发生或模型完成时间 |
| 保护网段 | 每行一个规范、已掩码的 IPv4 / IPv6 CIDR，最多 32 个；拒绝重复、非规范形式和 IPv4 映射 IPv6 |

示例表达式：

```cel
confidence >= threshold && verdict == "confirmed" && outcome == "attempt"
```

表达式只决定是否形成策略候选。即使模型自报分数为 1，仍须通过独立的策略授权、当前材料与设备门槛；规则命中、攻击尝试、利用成功和阻断效果是独立事实。未经明确评分授权的配置不能保存为自动模式。

| CEL 变量 | 类型 | 含义 |
| --- | --- | --- |
| `confidence`、`threshold` | double | 模型自报分数与策略阈值 |
| `verdict` | string | `undetermined`、`suspicious`、`false_positive`、`confirmed` |
| `outcome` | string | `unknown`、`attempt`；当前没有凭模型输出认定利用成功的值 |
| `recommendation` | string | 原研判建议：调查、通知或源 IP 封禁候选 |
| `protocol` | string | 冻结材料中的应用协议；缺测为空字符串 |
| `reference_count`、`missing_count` | int | 模型引用事实数和缺失证据项数 |
| `evidence_limited` | bool | 部分索引字段因格式或长度未完整提供 |
| `needs_review` | bool | 原研判要求人工复核，当前合格输出为 true |

采用 `cel.dev/cel-go v0.32.0` 的官方实现，使用规范模块路径，不自建表达式解释器。解析递归最多 32，错误恢复最多 8，实际计算成本上限 1000，单次计算上下文时限 100 ms；不注册宏、扩展函数、文件、网络或设备操作。通过类型检查的表达式仍可能发生除零、正则错误或成本超限；此时结果为不参与决策，不推定为安全。

## 研判与来源核验

服务端读取策略当前头和本人未到期的研判作业，在同一租户事务中核对：

1. 当前账号仍启用、角色与修订仍有效。
2. 策略期望修订与当前头一致，定义摘要和字段符合契约。
3. 作业请求、模板、告警身份、原始事件摘要与冻结材料一致，材料摘要重新计算相等。
4. 作业和结果均成功、未取消、存在合法结构化回答，并且尚未到期。
5. 材料观测时间未在未来且不超出策略时限。
6. 源 IP 封禁候选存在可解析的单播地址，且不在保护网段；NAT、资产归属、终端执行和真实设备效果仍不能由该地址单独证明。

结果绑定策略标识／修订／摘要、研判作业、提供方／修订、告警、原始事件与材料 SHA-256、评估时间和实际计算成本。前端独立核对定义及冻结材料摘要、所选作业和策略修订；来源不一致时拒绝展示为有效评估。

| 结果 | 业务含义 |
| --- | --- |
| `matched` | 表达式为真，形成候选，未授权执行 |
| `not_matched` | 表达式为假，不代表告警安全或攻击不存在 |
| `protected` | 源 IP 属于保护网段，排除该封禁候选 |
| `abstained` | 策略停用、研判不具备条件、材料超时、源 IP 无效或表达式执行失败 |

回执保留原研判的五项材料限制，并保留原有影子判断与未校准分数的执行边界。持续任务的执行授权由独立档案说明，不改写判断档案。判断不参与时没有分数或计算成本，不用 0 代替缺测；表达式运行失败时可保留已经读取的自报分数和实际成本。

## 持久化与权限

`decision_policies` 保存当前配置头，`decision_policy_revisions` 保存不可变历史。两表按租户强制行级隔离；运行角色可以维护当前头，不能更新历史修订。保存策略、追加历史、原提交回执与操作审计同事务提交；CAS 冲突不会覆盖其他维护者。

同一请求键和相同输入返回原回执，相同键但不同输入返回冲突。网络断开、超时或摘要不一致时，前端保留原输入和请求键并锁定编辑；“核对原提交”复用原请求，完整确认后才显示保存成功。

每租户最多 64 个策略，停用策略仍计入额度。滚动 24 小时最多 1024 次配置变更和 1024 次影子评估，两项额度独立计数；评估与审计计数使用租户事务锁，跨实例不能超额提交。历史修订按 `operations` 分类策略默认保留 180 天，并支持用户配置；当前配置受引用保护，不因创建满 180 天失效。`decision_evaluations` 保存结果、原策略快照和全量档案摘要，与操作审计同事务提交；运行角色不能 UPDATE 历史，未到期记录不能 DELETE。只保存判断及策略元数据，不复制提供方凭据、研判原文、原始载荷或 PCAP。档案按创建时的 operations 策略固化期限，默认 180 天。到期记录不可访问，由有界历史清理器回收；存量期限不会因策略编辑漂移。

持久评估提交要求 Idempotency-Key。同键同输入返回原档案，不再次求值或消耗评估额度；相同键不同输入返回冲突。原记录尚未到期时，即使策略已改变或材料已回收，原提交确认仍返回历史快照。到期档案不会因确认请求复活。前端遇到超时、断线或不完整摘要时保留原键与冻结材料，锁定输入，提供“核对原提交”；未经完整确认不会显示成功。

目录只返回当前账号在本租户的未到期记录，不授予管理员读取其他成员材料的权限。结果按租户持久提交序号倒序、有界 keyset 分页；新记录在刷新首屏后可见，后续页不插入新提交。游标属于本人有效档案，到期或不可访问时统一拒绝。目录不是全量 PIT 快照，清理可能缩短后续页。

## 接口与验收

公开契约见 [平台 OpenAPI](../api/openapi/platform.json)：目录、指定历史修订、维护配置、语法校验和按需评估共八个操作。请求拒绝未知字段、重复键、大小写别名及不支持的查询参数，写请求最多 16 KiB。修改与评估要求有效管理员和 CSRF 校验；语法校验允许有效只读账号。

持久入口为 `POST /api/v1/decision-evaluations`，目录与详情使用同一路径 GET；原 `decision-policies/{id}/evaluate` 入口保留兼容，每次调用也保存独立档案，但不提供原提交幂等确认，管理页面使用持久入口。

测试覆盖表达式边界、损坏与过期材料、未校准分数、保护网段、成本超限、角色撤回、跨租户访问、CAS、幂等、配额、事务中断、历史清理和前端未知提交。原生采集与实际 ZIP 链路复用真实 HTTPS 研判结果验证策略来源绑定，不以人工填分数替代真实研判材料。实际运行结果、源码及制品身份见 [测试覆盖与验收记录](测试覆盖与验收记录.md)；策略子流程通过不能替代完整自动响应能力验收。
