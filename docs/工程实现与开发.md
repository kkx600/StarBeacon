当前测试、部署与历史证据统一见[测试覆盖与验收记录](测试覆盖与验收记录.md)，后续范围与完成条件见[实施与验收计划](实施与验收计划.md)。工程源码测试、真实网卡链路、页面交互、实际发行包和生产容量分别核验，不能相互授予资格。

决策策略提供有界 CEL 定义、不可变修订、保护网段与按需影子评估，复用本人冻结研判。影子判断本身不授权设备动作；管理员可在原评估中独立确认一次限时处置，目标来自原评估，提交时核对当前材料和执行资格，原键核对返回原任务与原期限。模型配置中的独立页签通过表格与弹窗维护，持续模式绑定模型修订，处理当前修订启用后创建并完成的本人研判；独立开启自动研判许可后，指定探针与等级的新观测告警按日额度自动登记和提交，执行前再核对当前许可；自动模式在不可变独立档案中核对事实、探针与设备、去重、冷却及预算，再原子提交签名限时任务。自动模式不能通过人工确认接口再提交。详见[决策策略与影子评估](决策策略与影子评估.md)、[持续决策与自动授权](持续决策与自动授权.md)及[研判处置确认](研判处置确认.md)。自动研判的规模/故障恢复验收、跨账号托管、多级审批、置信度校准与真实设备效果仍须交付。

应用识别规则提供产品名称与类别、HTTP Host／可见 SNI／DNS 条件、组合与排除依据、不可变修订、输入验证和独立单探针部署。管理员冻结规则摘要、注册代次和当前状态；采集器经同步持久化后切换匹配器，分类与原字节共同进入 WAL，平台按原部署复算。告警、协议记录、安装回执和探针详情分别展示对应依据。输入验证、实际分类和应用字节计量具有独立边界，详见[应用识别规则与采集器分类](应用识别规则与输入验证.md)。

已实现子流程不能替代整项功能。当前远程结果分别绑定后端、前端和 ZIP 来源，不继承历史截图或旧构建资格；原生角色替换可能产生捕获缺口。置信度领域评测、全量告警自动研判、具体设备效果、平台灰度与系统／检测引擎升级、应用会话归因与计量、文件沙箱、集团治理和生产容量仍有缺口。真实外部条件未具备的功能按未验收记录，不能用受控协议通过替代领域效果。原始失败和历史验收集中保留于[测试覆盖与验收记录](测试覆盖与验收记录.md)。

```text

├── cmd/

│   └── openapi/               # 当前平台与采集器 HTTP 契约
├── migrations/                # Goose SQL 与嵌入资源
├── web/
│   ├── platform/              # 平台 Vue 应用
│   ├── collector/             # 采集器独立 Vue 应用
│   └── packages/shared/       # 类型、主题、会话客户端和公共组件
├── deploy/                    # 开发依赖 Compose、NATS 配置、Go 镜像与同源代理示例
├── scripts/                   # 开发初始化、环境加载、样本与集成入口
├── tests/integration/         # 真实 PG/NATS/ES/mTLS 测试
```

模块依赖保持单向：入口 → 配置与组装 → 平台／采集／接入／分析 → 契约与存储。当前一个 Go module、五个二进制；前端两个独立应用共用一个 pnpm workspace。模型、取证与设备连接器使用各自受限的适配边界，不复制协议解析器、数据库驱动或密码算法。设备联动的配置、协议、文件权限和结果未知处理见[HTTP 联动与限时封禁](HTTP联动与限时封禁.md)。

## 4. 本地启动

需要 Go 1.26.8、Node 24.19.0、pnpm 12.6.0、Python 3、Docker 与 Compose plugin。首次从仓库根目录运行：

```sh
make dev-setup GO=/绝对路径/go
```

`dev-setup` 编译五个入口、生成独立随机凭据、启动开发依赖、迁移数据库、建立非超级用户运行角色、初始化本地租户和管理员、签发开发证书、登记采集器，并建立独立平台命令签名密钥及采集器信任公钥。配置保存在 Git 忽略的 `.local/`，目录权限 0700，凭据及私钥 0600。重跑保留已有凭据、账号和采集器身份；匹配失败时返回错误，不重置管理员密码。

开发 Compose 仅包含 PG、Redis、NATS 与 ES，不包含 Go 角色、前端、Nginx、MinIO AIStor 或原生 Suricata。启动命令读取已经编译的二进制，不再使用 Go 编译器；后续重新构建或运行集成测试仍须沿用精确工具链。

### 4.1 EVE 数据入口

开发默认读取 `.local/eve.json`。`make sample` 向它追加一条明确标记的工程验收 EVE，使用保留示例 IP，不向外部网络发送攻击流量。此样本验证上报和索引流程，不证明真实 Suricata 抓包或规则命中。

接入已有 Suricata 时，在采集器环境中配置 `SB_EVE_PATH`，给代理只读文件和轮转目录权限；确认 Suricata 实际版本、EVE 输出和 Ethernet 字段配置。使用 rename/create 轮转，保留旧 inode 到代理读完；检查点后旧文件已被删除时，读取停止并报告异常，不默默跳过缺失来源。copytruncate 即使有前缀检测也不能保证在所有覆盖／快速增长情况下识别，不能作为可靠生产轮转策略。

当前代理每轮最多读取 100 条／约 2 MiB，完整换行后才推进偏移；单条超过 1 MiB 时停止读取并报告异常。它不把超大原文截断为正常告警。处理大包、TCP 重组和检查深度仍由真正的捕获与 Suricata 模块验收，不能把 EVE 大小限制当成大包检测能力。

Linux 托管模式设置 `SB_CAPTURE_MANAGED=true`，使用可信 Suricata 8.0.7 模板及 tcpdump BPF 编译器。模板、分类／引用／阈值文件经过有界读取，私有工作目录由采集器维护；不得引用外部 YAML 或插件。每张网卡支持 1–64 个线程，最多 16 张网卡、总计 128 个线程；BPF 按 UTF-8 字节计最多 2048。先隔离执行规则装载和无网卡 BPF 编译，再停旧进程、启动并确认实际 AF_PACKET 轮询。混杂模式与内核校验和卸载标记仅用于捕获，不修改宿主网卡的卸载设置。配置应用会产生采集间隙，应在维护窗口执行；捕获状态与期望配置分开保存，不能把 HTTP 成功响应视为检测已生效。

`SB_CAPTURE_SPOOL_BYTES` 默认 1 GiB、至少 100 MiB，`SB_CAPTURE_ROTATE_BYTES` 默认 64 MiB 且不超过暂存额度的一半，可配置为 1 MiB 到半额度。托管模式采用持久轮转记录、单个待排空来源和原生 `reopen-log-files`；实际检测进程关闭旧 inode、全部字节进入 WAL、后继来源断点原子提交后才回收旧文件。中断恢复核对身份、前缀和排空位置，不跳过缺失来源。暂存超额或轮转无法核对时停止检测并报告异常，待传事件继续保留；两秒监控不是文件系统硬配额，生产仍须独立磁盘额度和容量告警。EVE 属于检测流水线暂存，不代替默认 180 天的 PCAP／业务数据归档。

### 4.2 通知与模型出站

平台与 Worker 通过 `SB_CREDENTIAL_KEY` 或对应 `_FILE` 注入同一 32 字节十六进制加密密钥；不入 Git、镜像、API 或审计。`SB_OUTBOUND_PRIVATE_NETWORKS` 明确允许的私网 CIDR，`SB_OUTBOUND_CA` 指定受信任 CA。固定 DNS/目标校验、禁用环境代理、禁止元数据地址；生产办公 HTTP 出站要求 TLS，Syslog TCP 仅用于开发。没有密钥时页面显示服务未启用，不能配置或测试。模型公网调用需要提供方 `allow_external` 明确允许。

模型连接测试使用固定短文本，最多 15 秒请求、64 输出 token，预算以 UTC 日和当前不可变修订核算；同一提供方一个请求、每租户跨实例四个。输出拒答、截断、凭据失败和未知结果分别记录；无完整用量或耗时证据就显示未知，实际观测到的零值保留为零。没有自动重试可能已经计费的请求。通知摘要不含 IP、URL、载荷或密钥，每个邮件接收人独立 outbox；未知结果人工核实后才重试，渠道受理、已读、TCP 完整写入和远端落盘分开。


#### Syslog 审计外发

在通知渠道中选择 Syslog TLS，并选择“安全告警”“操作日志”“登录日志”。历史配置及未指定类别的新渠道默认只发送告警；办公通知渠道只能发送告警摘要。编辑未指定类别时保留既有范围，空类别配置无效。告警级别只筛选安全告警，审计专用渠道不必配置告警级别。

操作与登录审计在原事务中写入绑定渠道修订的脱敏投递材料；服务中断后仍可继续领取待投递记录，不依赖内存缓冲或易遗漏的时间游标。保存渠道本身也属于操作审计。停用或静默时记录抑制状态；配置修订发生变化后取消原修订的待投递任务，不将旧目的地悄然换成新目的地。投递过程失败、未知结果、人工重试和重复风险沿用通知队列契约。

每个审计帧包含原始审计 ID、类别、时间、账号或数据库操作角色、动作、对象、请求标识、来源 IP 和受限 User-Agent；登录帧包含验证结果与阶段。仅证明密码验证结果，不能当作已建立完整会话。超限或控制字符处理后标记 `truncated`，不伪装完整原件。密码、请求正文、配置凭据和操作原因不进入外发材料；审计详情仍按平台权限查看。无法确定租户的登录失败保存在平台审计中，不猜测租户或向任一租户外发。

审计帧使用 RFC 5424、六位以内时间小数和 UTF-8 BOM；TLS 按 RFC 5425 的 UTF-8 字节数分帧。[RFC 5424](https://www.rfc-editor.org/rfc/rfc5424)、[RFC 5425](https://www.rfc-editor.org/rfc/rfc5425)。Syslog 的发送容量由有界工作进程控制，不套用办公机器人的三秒间隔。投递材料保留期为通知策略与来源日志到期时间中的较早者，两者默认均为 180 天。`transport_written` 只表示传输写入，不确认远端落盘。原始 EVE、普通进程日志全集、历史补发及大流量容量仍需独立交付和验收。

### 4.3 规则与样本验证入口

平台「规则管理」创建规则包修订并选择探针装载检查；两端的重放样本与任务分属独立页签。共享 CodeMirror 编辑器提供高亮、行号、撤销、换行及点击定位，基础诊断检查受控 `alert` 规则的头字段、引号／转义、括号结构、末分号、SID 范围／重复、rev 及 900 KiB 上限；它不是完整 Suricata 解析器。关键词、变量和引擎兼容必须由选定探针的原生 `-T` 确认。需要受信任的 Suricata 8.0.7 与隔离环境，在采集器配置 `SB_SURICATA_BINARY`、`SB_SURICATA_CONFIG`，需要登记规则快照时再配置 `SB_SURICATA_RULES_PATH`。具体限额、样本存储、Linux 隔离依赖、生产 S3 和结果解释见[PCAP 重放与规则验证](PCAP重放与规则验证.md)。普通 Go scratch 镜像不能直接作为包含原生重放环境的采集器镜像。

## 5. 交付、隔离与恢复语义

1. 证书 URI 唯一绑定租户、探针和注册代次，TLS 1.3 验证信任链。PG 业务事务使用 transaction-local 租户设置，业务记录采用 FORCE RLS；既有登录身份读取是专门例外，用户维护使用固定受控函数重新核对当前租户及操作者，运行角色不能直接写入身份表。启动检查原始连接身份、会话身份及有效角色，拒绝超级用户、BYPASSRLS、CREATEROLE、CREATEDB、REPLICATION，以及直接持有、继承或可切换取得的业务表所有者权限；检查覆盖 `public` 与 `starbeacon_jobs` 全部表，不依赖手工维护的表名清单。既不能继承也不能切换的普通成员关系不作为特权使用。
2. 事件 ID 由注册代次、来源代次、原文偏移和行内序号确定。bbolt 同一同步事务保存数据、序号、额度和来源检查点；额度不足时全部回滚，不能只保存部分记录却推进来源。
3. 平台路由固定 UTC 日期分区，重试继续使用原路由。接入每帧核验启用状态、路由、范围、摘要和身份，JetStream PubAck 成功后才返回精确 ACK。
4. 采集器仅回收与当前批次身份、原文摘要及精确序号范围一致的数据。它不根据一个无范围的全局水位删除其他流、旧注册或缺号区间。
5. Alerts／Context 使用 WorkQueue、File Storage、`MaxAge=0` 和 `DiscardNew`。未索引数据不被时间淘汰；满载拒绝新发布，使本地队列与来源产生背压。共享索引消费者在全部有效文档／隔离记录和已索引通知持久化后 DoubleAck，回收接入缓冲。[JetStream 留存语义](https://docs.nats.io/learn/jetstream/retention-policies)
6. ES Bulk 逐项核验；201 为新写入，409 必须核对不可变来源和原文摘要，429／依赖故障重试。400 映射拒绝、无效 EVE、无效 UTF-8 或事件流不匹配进入持久隔离，不伪装成正常告警。

传递保证是至少一次加幂等索引。NATS 2 分钟去重窗口不是跨重启的永久唯一保证；稳定 ES `_id` 和 409 来源核验承担长期重放边界。接入 ACK 表示队列持久接收，Worker DoubleAck 表示索引流程完成，ES refresh 后才可搜索，三者不合并。

工作队列不是供多个独立分析订阅者共享历史的总线：WorkQueue 不允许重叠的独立消费者。后续分析从已索引通知／ES，或经过明确设计的独立持久分发流读取。当前已索引通知为 72 小时运行缓冲，隔离记录为默认 180 天，各流默认上限 256 MiB；通知消费者在摘要持久进入 PG outbox 后才确认通知消息；投递日志默认 180 天，与 72 小时运行缓冲分别治理。不能将运行缓冲 TTL 当成业务留存，也不能靠提高 TTL 无限积累消息。

本地 WAL 默认 256 MiB，配置 `SB_WAL_BYTES`；该额度是待传记录编码字节，bbolt 文件可以保留更大的已分配页。暂未实现在线压缩及离线 compaction 编排。队列满会停止源读取，Suricata 文件轮转容量和磁盘配额也必须承接背压；任何容量都不足时需要显式报警和缺口处理，当前不会自动清队列换取继续运行。

ES 索引默认每租户／路由 UTC 日期／数据流一个主分片及一个副本，以首次路由日期作 ILM 起点。此实现便于验证身份和重放，不能直接外推到大量 SaaS 租户；租户打包、分片预算、PIT、热点和数据单元调度另需实现与容量测试。当前检索单次范围最多 31 天、页大小最多 100、最多前 10000 条，不是无限历史遍历。

## 6. 留存、凭据和执行边界

PG 为 `alerts/pcap/network/operations/logins/notifications/reports/files/asset_history/models/incidents` 十一类初始化 180 天默认策略，迁移补齐缺失类别并保留已有自定义天数。管理员在「数据留存」配置 1–3650 天，通过五分钟创建人预览、CAS 与精确幂等发布；操作审计、发布记录与策略同事务。仅支持未来对象，当前未开放存量期限重算。

索引 Worker 始终需要最小权限 PG 账号读取策略。告警／网络事件的租户 UTC 日期分区首次创建时固定 ILM，旧分区不因策略变更调整，同日数据仍沿用已固定期限。自有 ES 模板关闭匹配索引的自动创建，模板或已有生命周期定义漂移时拒绝覆盖；索引不存在导致的写入失败会清除本进程缓存，并由受控创建路径重建。缓存只在同一索引或策略内合并并发，不串行阻塞不同分区。

操作、登录、资产历史、模型／通知配置历史、分析作业、任务及重放样本在创建时读取所属类别策略并记录到期时间。活跃配置独立保存；文件类别策略已登记，流水线尚未接入。本地审计在写入时有界清理；平台每分钟按固化期限回收已接入的 PG 历史和短期对象。每轮 20 秒／32 个租户／4096 条，单租户最多 1024 条、单表最多 256 条；分类续点与删除同事务，锁冲突回滚，跨实例跳过被锁定的维护行。当前配置、活动任务、未知规则安装及被引用版本受保护。匿名登录记录仅在无业务租户的维护事务中回收，普通租户查询不可见。规则历史、物理分区、全域保全、存量重算及备份销毁尚未完成。重放样本已执行对象与目录清理，但持续捕获及全域生命周期未完成，不能据此声称全部业务生命周期已经落地。

开发证书只用于回环联调：CA 有效期 365 天、服务及探针证书 30 天。开发 CLI 支持 `dev-pki --server-hosts` 显式附加 DNS/IP SAN，并保护文件创建失败的原子回收；续签、撤销、轮换、失效预警和生产证书发布仍需实现。运行进程不持有 CA 私钥或迁移 DSN；CLI 是独立运维工具，开发脚本配置中的私钥不得作为生产镜像层或仓库文件。

生产模式要求依赖 TLS、PG `sslmode=verify-full`、ES API Key、HTTPS Origin 和至少 R3 的接入队列。所有 HTTP 当前仍只监听回环，跨主机入口需要受控网关／同源代理与内部可信 CA 配置。生产校验只阻止明显不安全配置，不代表已完成生产 HA、备份恢复、认证强度和权限验收。

登录与操作审计默认使用实际连接来源。单层受控代理部署时，平台和采集器可配置 `SB_TRUSTED_PROXY_CIDRS=127.0.0.1/32,::1/128`，只信任名单内的直接对端及其覆盖的单值 `X-Real-IP`；默认名单为空，拒绝全网范围、主机名与非规范网段。Nginx 模板在每个代理 location 覆盖该头并清除任意转发链，配置时须限制直连 API。缺失、重复或非法头退回连接来源；登录预算与审计使用相同规范地址。多层代理链及完整 SaaS 租户／账号配额仍需独立实现。NATS 三节点路由、各运行角色受限账号和依赖信任链仍需独立部署验收；当前仅提供回环开发配置，不能把开发 Token 复用到生产。

外部 EVE 模式保存采集目标返回 `not_applied`。托管模式的本机配置会生成私有检测配置并运行 Suricata，管理网络配置不由该流程修改。任务涵盖诊断、规则装载检查、离线重放、固定修订发布及中断核实。`rules.apply` 要求同一设备、注册代次、完整修订、基础配置和规范检测剖面的装载与独立正反样本回执，资格在一天内有效；平台核对原始签名命令和回执，数据库事务绑定规则文件摘要并写入审计。设备再次检查配置、完整规则来源、实际进程及文件摘要，原生阻塞重载和装载数量、文件回读符合预期才确认生效。历史修订作为新的授权发布任务部署；中断任务保留 unknown 回执，独立 `rules.reconcile` 取得当前事务的原生核实结果后才解除发布阻塞。剖面摘要绑定固定覆盖配置及分类／引用／阈值文件内容，不包含临时目录。自动灰度编排、来源分发和 TUF 尚未交付，远程验证见测试记录。设备联动已提供通用 HTTPS 限时任务、租约回读和条件解除，由指定采集器执行；隔离协议端点的受理与真实流量阻断效果分别验收。系统升级尚未实现，不能通过页面按钮执行任意系统命令。持续自动授权按绑定模型、本人新研判及固定设备边界运行，详见[持续决策与自动授权](持续决策与自动授权.md)。通知属于独立 outbox 流程，已提供真实协议发送与回执。

操作日志与登录验证记录 API 使用稳定游标，默认查询最近 7 天、单次最多 31 天和 100 行；平台健康 API 返回实际宿主资源及依赖状态。登录审计表示密码验证结果，在创建会话之前落库，不能将验证成功直接解释为会话创建成功。`/operations` 已提供运行状态、操作日志、登录日志独立页签及详情弹窗；全域查询／导出／决策／动作审计仍缺失。请求来源只信任连接地址，不使用任意转发头。
