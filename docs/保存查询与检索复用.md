# 星烽 StarBeacon 保存查询与检索复用

保存查询复用告警和协议记录的检索条件，不保存结果集、账号权限或可执行脚本。应用后仍通过原检索入口按当前执行账号重新检查权限。定时狩猎、参数化模板、服务身份、PIT 和异步结果导出尚未实现。

## 页面与操作

告警管理和流量记录工具栏提供“保存当前查询”和“已保存查询”。目录、查看、编辑各使用独立弹窗；目录采用紧凑条目列表，不在业务表格旁增加第二张表格。空目录、读取失败、校验失败、提交结果未知和解析失败分别展示。

保存定义包含数据集、条件／高级模式、全部筛选字段、解析器版本和时间窗口，不包含列表分页和结果总数。相对窗口支持最近 24 小时、7 天、30 天，在应用时按服务端 UTC 重算。固定窗口保持原起止时间，跨度最多 31 天；刷新和翻页不移动固定窗口。应用后同步表单字段，切换为相对窗口后重新计算时间。账号或租户切换清空私有目录、条件、详情和未确认提交。

协议记录条件包含记录类型、探针、探针注册标识、采集实例标识、流标识、源／目的 IP、协议、HTTP 方法和路径。流标识用规范十进制字符串保留 `uint64` 精度，不能单独作为跨探针会话身份。注册和采集实例条件须满足原检索入口的来源组合约束。告警高级模式不混入已隐藏的可视化条件。

编辑默认保留原定义；替换条件须显式选择“使用当前页面的查询条件和时间窗口”。没有实际变更时拒绝提交。停用定义可查看、不能应用；解析器不兼容时保留完整定义供核对，禁止静默忽略条件。

## 权限与隔离

个人查询默认仅自己可见和维护。只读账号可以保存个人查询，这不授予管理或原始载荷权限。团队共享须由具有管理员权限的所有者创建和维护；其他同租户有效账号可以读取和应用，不能接管。所有者降权后不能修改其团队查询；撤回共享后其他账号不能读取或应用。

数据库强制租户 RLS，查询目录显式约束所有者或团队可见性。读取、保存和解析在事务中复核当前账号、租户状态、角色与身份修订，并与账号权限撤回互斥。团队共享只共享定义。解析后调用原 `/alerts/search` 或 `/traffic/search`，再次核对当前会话、租户、来源和载荷权限。

## 接口与提交一致性

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/saved-searches` | 按数据集、名称、可见范围、状态和游标读取可见目录 |
| `GET /api/v1/saved-searches/{id}` | 查看可见且未到期的完整定义 |
| `POST /api/v1/saved-searches` | 创建、编辑、共享或停用，需要 CSRF 和原请求键 |
| `POST /api/v1/saved-searches/{id}/resolve` | 核对实例、修订、数据集及解析器，返回检索参数，需要 CSRF |

定义版本为 `saved.search.v1`，当前过滤解析器为 `1.0`。参数校验复用实际告警／流量检索服务，包括语法、IP、时间和来源组合约束，不接受任意 ES DSL。租户和所有者取自会话，不能由正文指定。

创建使用修订 0、空实例标识，服务端生成实例标识。编辑提交当前实例与修订，写入后修订加一。历史回收后同 ID 重建生成不同实例，旧确认不能作用于重建对象。配置、审计和不可变回执在一个事务内提交。

回执绑定租户、执行者、请求键和原输入摘要。同一请求键与完全相同输入重复返回原修订回执，即使对象后来编辑；改变输入返回冲突。网络中断或损坏回执不显示保存成功，字段锁定后通过“核对原提交”复用原输入与请求键。前端 30 秒等待期限不代表服务端已取消或回滚。

| 约束 | 限制 |
| --- | --- |
| 名称／用途说明 | 128／1,000 个字符，去除首尾空白，不含控制字符 |
| 写入正文 | 32 KiB，拒绝未知、重复和大小写别名字段 |
| 目录分页 | 默认 20、最多 100 条，ID 升序游标，名称通配符按字面匹配 |
| 配置数量 | 每账号 200、每租户 2,000 个未回收配置，含停用配置 |
| 变更预算 | 每租户最近 24 小时最多 10,000 个回执 |
| 修订 | 不超过 1,000,000，达到上限后拒绝编辑 |

不存在、过期与不可见统一返回 404；无权修改 403；输入错误 400；实例／修订／解析器冲突与停用 409；配额 429；存储不可用 503。不完整目录、损坏定义和损坏回执均不能当作成功。

## 留存与验收

启用查询属于有效配置，不因创建时间超过 180 天自动停用。停用定义、写入回执和操作审计使用操作类别留存策略，默认 180 天，可配置。回收先删除已到期回执，再删除停用、到期且无同实例回执引用的定义；活动配置不删除。

迁移为 `00032_saved_searches.sql`。运行角色可读写配置和写入回执，不能更新回执；历史删除受 RLS 到期条件限制。单元、真实 Vue／Ant Design Vue 交互和实际 PG／ES／HTTP 测试入口均已提供；以 [测试覆盖与验收记录](测试覆盖与验收记录.md) 中同一源码的实际结果为准。原型与合成响应不证明发布资格。
