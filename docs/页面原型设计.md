# 星烽 StarBeacon 页面原型设计

## 交付范围

页面原型服务于安全运营、实施与前端开发评审。118 个业务页面映射[功能覆盖与验收矩阵](功能覆盖与验收矩阵.md)中的全部 107 项需求；每页提供有数据、无数据、查看详情、操作表单、加载中、加载失败六种状态，共 708 个业务状态。登录、多因素认证、找回密码、会话过期、403、404、500、租户授权不足另外提供八个边界页面。

交互工程位于 [prototype](../prototype/README.md)，完整图片位于[图片目录](../prototype/public/screenshots/index.html)，需求与路由映射位于[页面清单](../prototype/public/page-manifest.json)。页面记录与指标均为合成示例，不代表已经接入真实数据或通过性能验收。

图片交付包含 716 张基础状态图与 12 张业务详情图，合计 728 张。业务详情图单独呈现通信原包与载荷、证据缺口、响应未知结果、授权明文来源、规则验证演示、报告正文、案件任务、对话证据和留存影响预览。

## 布局与页面语言

控制台采用白色侧栏、白色内容面板与浅灰工作区。桌面侧栏宽 220 px、顶栏高 56 px、页面标签高 44 px，蓝色用于主要操作和可进入的记录；告警严重级别、执行状态和未知状态同时使用文字与颜色。字体使用系统中文字体，无远程字体依赖。

工作区顺序为页面名称及业务说明、关键状态、业务边界提示、筛选表单、表格工具栏、记录列表和分页。辅助说明直接表达证据边界或业务影响，不把过程性描述写成产品文案。页面顶端状态切换条仅用于原型评审。

899 px 及以下使用紧凑布局；550 px 及以下收起侧栏，表单改为单列，图表纵向排列。长表格在表格内部横向滚动，不扩宽整个页面。折叠导航不保留子菜单浮层；移动端可以从顶栏展开导航。

## 通用交互

| 场景 | 页面行为与内容 |
| --- | --- |
| 有数据 | 使用本工作域的列、状态和示例记录，支持查看详情及可授权的操作路径 |
| 无数据 | 说明当前没有记录的业务原因，提供查看数据源、建立配置或恢复条件的入口；空状态不被解释为没有风险 |
| 查看详情 | 弹窗内展示对象身份、业务字段、依据、关联对象和记录；复杂工作域采用页签 |
| 操作表单 | 依据本工作域配置字段，进行必填和局部业务规则校验；提交仅更新当前内存中的示例对象 |
| 加载中 | 在记录区域显示加载状态，保留页面身份及已输入查询条件 |
| 加载失败 | 说明当前记录无法载入，提供重试；不展示为没有结果 |
| 权限不足 | 说明身份、对象或租户范围尚未获准访问，提供合法的返回路径 |

记录列表提供可见字段关键词匹配、状态和网络域筛选、按列排序、分页、列显隐和记录选择。适用工作域提供源 IP、目的 IP、协议、HTTP 方法、Path 与时间条件。日期字段保留完整值，横向空间不足时可以在表格内部继续查看。

详情和操作通过弹窗连续进入；只读日志的操作状态为导出表单。批量修改作用于实际勾选的示例记录，当前告警页的批量研判不创建虚构的新告警。CSV／JSON 导出只包含本地示例筛选结果；CSV 对可能被电子表格解释为公式的值进行转义。

## 专用工作区

### 态势总览、拓扑与大屏

态势总览展示安全事件、高危告警、在线探针、捕获质量、当前观测流量、告警趋势、威胁类型、重点告警、资产组风险、响应进度及运营待办。捕获异常与数据源离线会提示对结论的影响。

拓扑展示节点、网络域与通信关系，选择节点后进入资产及风险摘要。态势大屏使用独立深色工作区，展示流量、威胁、应用分布、探针状态和处置进度；可进入全屏查看。大屏数据同样为合成示例，不承诺实时刷新能力。

### 告警检索与通信证据

高级检索提供表达式、可视条件和语法帮助。原型对其支持清单中的字段比较、布尔组合、集合、CIDR 与协议存在进行本地筛选；未知字段、非法表达式和未实现语义显式报错。生产系统的事件投影与原生数据包两种模式，以及多值、正则、切片和协议层语义，仍须按[高级检索与数据包取证设计](高级检索与数据包取证设计.md)实现与验收。

通信详情提供数据包列表、协议树、源／目的 MAC、精确捕获时间、TCP 标志、HEX、ASCII 和 UTF-8 尝试解码。点击 HEX 字节会显示应用载荷偏移。MAC 说明其镜像观测来源；单臂旁路的入站／出站时间显示“不可观测”，不生成推定值。

HTTP 示例包含 SYN、SYN/ACK、ACK、请求／响应及 FIN/ACK 序列，所有帧均明确标记合成示例。未提供相应原包的 DNS、TLS 等告警不会套用 HTTP 原包。UTF-8 解码不改变原始字节，TLS 密文不作推定解码。真实 PCAP、会话完整性、解密资格与导出任务以工程设计为准。

### 规则与 AI 工作台

规则工作台覆盖自然语言、HTTP Raw 和 PCAP 文件名输入，展示候选规则、合成正负样本结果、性能边界与发布路径。原型不读取上传样本、不调用模型、不执行 Suricata。生产流程必须保留候选、目标引擎验证、回放、签名发布、探针回执和回滚的独立状态。

智能对话展示本地示例回复、证据引用与工具轨迹；模型配置、路由、评测、预算、决策策略和 MCP 权限分别有管理页面。Jev、Laya 等适配器按工程契约与评测接入，不把原型选项视为模型已可用。日报、周报、月报提供列表、计划、报告正文、审核与导出页面路径。

### 研判、响应与联动

告警详情保留原始检测、攻击结果、研判依据、处置授权和处理记录。缺少终端或应用证据时，攻击结果仍为“无法判定”。自动化策略分别配置影子、审批及自动模式，并展示校准版本、证据资格、授权、保护名单、TTL、预算与撤销约束。

响应任务呈现平台下发、执行采集器、设备接受、配置回读和效果观察的链路。接受、配置生效与流量效果分别展示，结果未知的写操作保留核对路径。设备 API、认证插件、执行器租约和紧急控制有独立页面；任何原型操作均不会访问防火墙或 EDR。

置信度内部采用 0–1，表单、列表、详情和导出保持同一单位转换；`0.97` 表示 `97%`。策略的启用、待验证和停用属于生命周期，影子、审批和自动属于运行模式。响应回执、效果与证据快照绑定当前对象，不使用固定成功事实覆盖记录状态。

### 资产、事件与运营治理

资产中心覆盖资产、接口与 MAC、地址观察、网段、资产组、NAT、身份、标签、漏洞和修复任务。案件详情提供关联告警、时间线、协作任务和笔记；事件与案件生命周期、SLA 和权限的真实实现依赖业务后端。

日志源与 Syslog 入站／出站、邮件、企业微信、钉钉、飞书、Webhook、投递规则、推送日志与失败投递均有管理入口。探针页面覆盖 CPU、内存、磁盘、流量、丢包、版本、升级、配置及离线状态；平台运行、依赖、队列、存储、审计、登录日志、租户、角色、API 与资源配额分别列出。

### 留存与证据保全

已启用业务数据默认均为 180 天，包括全量 PCAP、告警、操作／登录日志、推送记录、文件样本及报告；支持按租户和类别调整。策略弹窗展示当前期限、目标期限、合成待清理范围、保全排除、变更依据和影响确认。

保全对象、当前有效配置和活动业务对象排除自动清理；延长期限不能恢复已删除的数据。认证、缓存与传输缓冲采用独立运行 TTL。容量估算采用无压缩基准：平均速率 × 86,400 秒 × 天数 ÷ 8 × 冗余倍数；1 Gbit/s、180 天、单份约为 1.944 PB，不含索引、备份与运维余量。压缩收益必须实测。

## 组件与后端边界

前端采用 Vue 3 Composition API、`script setup`、TypeScript、Ant Design Vue、Vue Router、ECharts 与 dayjs。版本、运行方式和锁文件见[原型启动说明](../prototype/README.md)。布局参考 Soybean Admin Ant；业务组件和素材由本仓库实现。

本原型没有后端、真实认证、租户隔离、ES 查询、对象存储、gRPC、MCP 服务、协议解析引擎或响应连接器。输入文件名、模型演示、规则验证演示、报表正文及设备回执均为本地示例。生产前端接入时，应使用[接口与数据契约](接口与数据契约.md)中的权限、分页、任务、查询快照、脱敏和状态机约束替换原型数据源。

## 核对方式

覆盖脚本核对功能矩阵与页面配置；构建执行 `vue-tsc` 和 Vite；实际浏览器核对筛选、表达式报错、表单校验、HEX 偏移、状态切换和响应布局。图片完整性脚本核对全部状态文件、JPEG 实际尺寸、页面横向边界、来源与 SHA-256。

每个状态的图片对应实际组件渲染，不以重复的占位图代替详情或操作图。原型截图只证明页面结构和示例状态，不能替代协议、性能、模型准确率、设备联动或故障演练验收。

文件与来源核对覆盖全部图片；人工目视检查采用代表页面，窄屏目视核对覆盖态势总览。图片目录的模块、状态筛选及链接已在服务模式下验证，本地文件模式未在内置浏览器中执行。
