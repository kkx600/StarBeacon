# 星烽 StarBeacon 页面原型设计

## 交付范围

页面原型服务于安全运营、实施与前端开发评审。主控平台的 42 个主导航工作区承载 115 个功能视图，头像菜单另有 1 个个人设置视图，合计 116 个主控功能视图，映射[功能覆盖与验收矩阵](功能覆盖与验收矩阵.md)中的全部 107 项需求；采集器另提供 5 个独立工作区。每页提供有数据、无数据、查看详情、操作表单、加载中、加载失败六种状态，主控 696 个、采集器 30 个，合计 726 个业务状态。主控平台另提供登录、多因素认证、找回密码、会话过期、403、404、500、租户授权不足八个边界页面；采集器提供本地登录、多因素认证和会话过期三个边界页面，共 11 个。

交互工程位于 [prototype](../prototype/README.md)，完整图片位于[图片目录](../prototype/public/screenshots/index.html)，需求与路由映射位于[页面清单](../prototype/public/page-manifest.json)。页面记录与指标均为合成示例，不代表已经接入真实数据或通过性能验收。

图片交付包含 737 张基础状态图与 43 张补充图，合计 780 张。业务详情图单独呈现通信原包与载荷、证据缺口、响应未知结果、授权明文来源、规则验证演示、报告正文、案件任务、对话证据、留存影响预览、探针运行详情与阈值、PCAP 导出结果，以及采集器的配置、校验、注册、同步、升级、规则回滚和维护申请。

## 采集器本地管理

产品采用采集器与主控平台两种部署形态。原型的主控平台保持 42 个工作区、116 个功能视图（工作区内 115 个，个人设置 1 个）；采集器有独立导航、五个本地工作区，以及本地登录、多因素认证与会话过期页面。两种入口当前由同一本机开发服务演示，生产需要分别构建、部署和鉴权。

| 采集器工作区 | 路由 | 页面内容 |
| --- | --- | --- |
| 运行状态 | `/collector/overview` | 本机资源、镜像与管理口、引擎与规则、上报确认、任务详情 |
| 网络与采集 | `/collector/network`；`view=capture`／`replay-samples`／`replay-tasks` | 网卡与地址、采集配置、重放样本、重放任务分别进入独立视图；网卡身份、管理地址、镜像口、BPF、线程与深度保留详情及申请入口 |
| 平台接入 | `/collector/connection` | 平台地址、mTLS、证书引用、注册密钥、证书查看与轮换申请 |
| 规则与升级 | `/collector/updates`；`view=system` | 目标与实际版本、自动／定时／手动同步设置、Agent／引擎／系统镜像升级、规则回滚、任务阶段；系统回滚无登记制品时禁用 |
| 系统维护 | `/collector/maintenance`；`view=audits` | 时间与存储、缓冲配额、服务维护、诊断包申请、本地操作日志 |

五个工作区均提供六种状态，复用既有表格、表单和弹窗组件。原型绑定 `SENSORS-0001` 总部核心探针的合成样机；主控平台探针详情“采集与版本”提供“采集器本地管理”入口。页面目录与图片目录将采集器单独列为一个模块；图片目录支持 `?module=collector` 直接筛选。

管理口不能选作镜像口，回环接口不可选；非法 IPv4／IPv6、链路断开、MTU／捕获长度、HTTPS 地址、线程和缓冲配额有本地输入检查。提交先检查当前草稿，再确认影响与创建申请；修改已检查字段后提交资格失效。申请、执行与实际配置分开，当前原型只生成待执行任务，实际配置与规则／版本不变。

注册密钥仅写，退出表单与提交后清空，不进入任务、操作日志或浏览器存储。凭据、网络测试、引擎验证、签名、规则重载、升级、自动回滚、认证及设备操作均不真实执行。离线制品只展示合成文件名，VLAN／Bond 与静态路由属于待实现的设备能力，不能从当前物理网卡样机推定支持。详细产品及接口约束见[采集器管理与部署设计](采集器管理与部署设计.md)。

## 布局与页面语言

控制台采用白色侧栏、白色内容面板与纯浅灰工作区（`#f7f7f7`）。桌面侧栏宽 220 px、顶栏高 56 px、页面标签高 44 px，亮蓝用于主要操作，链接蓝用于可进入的记录；绿色、琥珀色与玫红分别对应正常、关注与风险。指标保持白色背景，信息提示使用中性浅灰背景；告警严重级别、执行状态和未知状态同时使用文字与颜色。字体使用系统中文字体，无远程字体依赖。页面外沿为 16 px，主要区块间距为 12 px，常规面板内边距采用纵向 12 px、横向 16 px；899 px 及以下的页面外沿与面板横向内边距为 12 px。字号、表格行高及输入与按钮高度保持既有控件规格。

颜色由交互工程的 `src/theme.ts` 集中定义，覆盖主控平台、采集器、弹窗、认证与态势大屏。图表使用蓝、青、紫和橙色，并保留图例、数值和线型等区别；大屏采用独立深灰底、高亮蓝青色及独立的文字颜色。详情与表单通过根级变量继承颜色，不能在浮层中另设一套状态语义。静态主题检查覆盖 55 组文字配色（对比度至少 4.5:1）与 16 组图形／边界配色（至少 3:1）；这不代表全部交互状态的无障碍验收，实际组件的可读性仍由代表页面的浏览器核对确认。

工作区顺序为页面名称及业务说明、关键状态、业务边界提示、筛选表单、表格工具栏、记录列表和分页。辅助说明直接表达证据边界或业务影响，不把过程性描述写成产品文案。顶栏“原型状态”下拉仅用于原型评审。配置列表不显示没有对应业务口径的指标；探针统计与当前设备及筛选范围一致；总览、大屏和探针列表共用设备快照与健康阈值。其余态势图表为注明来源的合成场景，不代表联动计算结果。

899 px 及以下使用紧凑布局；599 px 及以下检索标题与控件允许换行，分段控件不超出容器；550 px 及以下收起侧栏，表单改为单列，图表纵向排列。长表格在表格内部横向滚动，不扩宽整个页面。折叠导航不保留子菜单浮层；移动端可以从顶栏展开导航。

## 导航与工作区

原型使用 History 路由，迁移旧 `#/` 链接；登录保留完整返回路径，同源返回地址需经过安全校验，未知页面进入 404。工作区的 `view` 查询参数支持直接访问、刷新和浏览器前进／后退；缺省或非法值回到该工作区默认视图。生产静态入口需按[工程实现与开发](工程实现与开发.md)配置 SPA 回退。

主导航按运营任务组织，功能需求不直接作为独立菜单项。同一对象的配置、状态和结果共用列表与详情；同一工作任务内的不同对象通过页签进入。已访问标签记录工作区，避免每次切换页签都创建新的顶部标签。个人设置从头像菜单进入。

探针列表与运行状态合为探针管理；PCAP 任务、完整性与导出结果合为 PCAP 取证；审计中的操作记录保留单一操作日志入口。通知渠道、规则、模板、推送日志与 Syslog 转发属于通知管理；检测规则与重放样本／重放任务、报告与生成计划、联动设备与认证插件分别归入对应工作区。数据源接入、平台运维、账号权限、租户和数据治理保持各自的工作职责。

## 通用交互

| 场景 | 页面行为与内容 |
| --- | --- |
| 有数据 | 使用本工作域的列、状态和示例记录，支持查看详情及可授权的操作路径 |
| 无数据 | 说明当前没有记录的业务原因，提供查看数据源、建立配置或恢复条件的入口；空状态不被解释为没有风险 |
| 查看详情 | 弹窗内展示对象身份、业务字段、依据、关联对象和记录；复杂工作域采用页签 |
| 操作表单 | 依据本工作域配置字段，进行必填和局部业务规则校验；提交仅更新当前内存中的示例对象 |
| 加载中 | 在记录区域显示加载状态，保留页面身份及已输入查询条件 |
| 加载失败 | 说明当前记录无法载入，提供重试；不展示为没有结果 |
| 权限不足 | 说明身份、对象或租户范围尚未获准访问，提供合法的返回路径 |

单个功能视图只呈现一个业务数据集；规则包、重放样本和重放任务使用独立页签，详情中的字段描述表不计作第二个业务列表。

记录列表提供可见字段关键词匹配、状态和网络域筛选、按列排序、分页、列显隐和记录选择。适用工作域提供源 IP、目的 IP、协议、HTTP 方法、Path 与时间条件。日期字段保留完整值，横向空间不足时可以在表格内部继续查看。容量采用 SI 的 B／KB／MB／GB／TB，速率采用千进制 bit/s；明确标注的 KiB 等二进制单位保留原义。整数和超过安全整数范围的值以字符串／BigInt 保留精度，混合单位按精确数值排序；缺测显示原因，与真实零值区分。

详情和操作通过弹窗连续进入；只读日志的操作状态为导出表单。批量修改作用于实际勾选的示例记录，当前告警页的批量研判不创建虚构的新告警。CSV／JSON 导出只包含本地示例筛选结果；CSV 对可能被电子表格解释为公式的值进行转义。

配置分类使用对应业务对象的值域：报告周期为日报、周报与月报，通知类型为邮件与办公通知渠道，发布内容为探针、引擎与规则等。数据来源与源 IP 使用不同含义的字段，权限模板与权限数量、有效期与到期时间分别存储。编辑表单将带单位的展示值转换为数值，未知选项要求重新选择；示例动作只能引用已登记的执行采集器。

## 专用工作区

### 态势总览、拓扑与大屏

态势总览展示安全事件、高危告警、在线探针、捕获质量、当前观测流量、告警趋势、威胁类型、重点告警、资产组风险、响应进度及运营待办。捕获异常与数据源离线会提示对结论的影响。

拓扑展示节点、网络域与通信关系，选择节点后进入资产及风险摘要。态势大屏使用独立深色工作区，展示流量、威胁、应用分布、探针状态和处置进度；可进入全屏查看。大屏数据同样为合成示例，不承诺实时刷新能力。

### 告警检索与通信证据

高级检索提供表达式、可视条件和语法帮助。原型对其支持清单中的字段比较、布尔组合、集合、CIDR 与协议存在进行本地筛选；未知字段、非法表达式和未实现语义显式报错。生产系统的事件投影与原生数据包两种模式，以及多值、正则、切片和协议层语义，仍须按[高级检索与数据包取证设计](高级检索与数据包取证设计.md)实现与验收。

通信详情提供数据包列表、协议树、源／目的 MAC、精确捕获时间、TCP 标志、HEX、ASCII 和 UTF-8 尝试解码。点击 HEX 字节会显示应用载荷偏移。MAC 说明其镜像观测来源；单臂旁路的入站／出站时间显示“不可观测”，不生成推定值。

HTTP 示例包含 SYN、SYN/ACK、ACK、请求／响应及 FIN/ACK 序列，所有帧均明确标记合成示例。未提供相应原包的 DNS、TLS 等告警不会套用 HTTP 原包。UTF-8 解码不改变原始字节，TLS 密文不作推定解码。真实 PCAP、会话完整性、解密资格与导出任务以工程设计为准。

### 规则与 AI 工作台

规则工作台覆盖自然语言、HTTP Raw 和 PCAP 文件名输入，展示固定的合成候选规则、合成正负样本结果、性能边界与发布路径。原型不读取上传样本、不调用模型、不执行 Suricata。共享 CodeMirror 6 编辑器支持行号、撤销、折行与错误定位；本地诊断只检查受控 `alert` 规则的基础结构（900 KiB、七个头字段、引号、括号、末分号、SID 与 rev），不是完整语法或语义解析器。未知关键词、变量及引擎兼容性须在工程中由选定探针原生 `-T` 验证。生产流程必须保留候选、目标引擎验证、回放、签名发布、探针回执和回滚的独立状态。

智能对话展示本地示例回复、证据引用与工具轨迹；模型配置、路由、评测、预算、决策策略和 MCP 权限分别有管理页面。Jev、Laya 等适配器按工程契约与评测接入，不把原型选项视为模型已可用。日报、周报、月报提供列表、计划、报告正文、审核与导出页面路径。

### 研判、响应与联动

告警详情保留原始检测、攻击结果、研判依据、处置授权和处理记录。缺少终端或应用证据时，攻击结果仍为“无法判定”。自动化策略分别配置影子、审批及自动模式，并展示校准版本、证据资格、授权、保护名单、TTL、预算与撤销约束。

响应任务呈现平台下发、执行采集器、设备接受、配置回读和效果观察的链路。接受、配置生效与流量效果分别展示，结果未知的写操作保留核对路径。设备 API 与认证插件通过联动设备工作区管理；执行器租约与紧急控制通过响应动作工作区进入；任何原型操作均不会访问防火墙或 EDR。

置信度内部采用 0–1，表单、列表、详情和导出保持同一单位转换；`0.97` 表示 `97%`。策略的启用、待验证和停用属于生命周期，影子、审批和自动属于运行模式。响应回执、效果与证据快照绑定当前对象，不使用固定成功事实覆盖记录状态。

### 资产、事件与运营治理

资产中心覆盖资产、接口与 MAC、地址观察、网段、资产组、NAT、身份、标签、漏洞和修复任务。案件详情提供关联告警、时间线、协作任务和笔记；事件与案件生命周期、SLA 和权限的真实实现依赖业务后端。

日志源与 Syslog 入站／出站、邮件、企业微信、钉钉、飞书、Webhook、投递规则、推送日志与失败投递均有管理入口。探针管理以同一设备列表展示连接、健康、CPU、内存、磁盘、镜像流量、丢包与心跳；详情承载基本信息、运行状态、采集与版本、运行记录。健康阈值可在当前原型会话调整；离线或心跳过期时当前指标不可观测，执行角色的捕获指标为不适用。目标版本与上报版本分开；升级需要发布任务回执。平台运行、依赖、队列、存储、审计、登录日志、租户、角色、API 与资源配额分别列出。

### 留存与证据保全

已启用业务数据默认均为 180 天，包括全量 PCAP、告警、操作／登录日志、推送记录、文件样本及报告；支持按租户和类别调整。策略弹窗展示当前期限、目标期限、合成待清理范围、保全排除、变更依据和影响确认。

保全对象、当前有效配置和活动业务对象排除自动清理；延长期限不能恢复已删除的数据。认证、缓存与传输缓冲采用独立运行 TTL。容量估算采用无压缩基准：平均速率 × 86,400 秒 × 天数 ÷ 8 × 冗余倍数；1 Gbit/s、180 天、单份约为 1.944 PB，不含索引、备份与运维余量。压缩收益必须实测。

## 组件与后端边界

前端采用 Vue 3 Composition API、`script setup`、TypeScript、Ant Design Vue、Vue Router、ECharts 与 dayjs，规则编辑器直接复用 `web/packages/shared` 的 CodeMirror 6 源码。原型安装／构建前先安装 `web` 的锁定依赖，Vite 对 Vue 与 Ant Design Vue 做 dedupe；源代码复用不要求同时运行工程前端或 Go 进程。版本、运行方式和锁文件见[原型启动说明](../prototype/README.md)。布局参考 Soybean Admin Ant；业务组件和素材由本仓库实现。

本原型没有后端、真实认证、租户隔离、ES 查询、对象存储、gRPC、MCP 服务、协议解析引擎或响应连接器。输入文件名、模型演示、规则验证演示、报表正文及设备回执均为本地示例。工程前端已接入的接口以 [`api/openapi/`](../api/README.md) 为准；其他能力继续按[接口与数据契约](接口与数据契约.md)中的权限、分页、任务、查询快照、脱敏和状态机目标替换原型数据源。
