# 星烽 StarBeacon 关联规则与窗口回测

关联规则用于核对已经进入平台检索的告警活动。规则目录位于 `/detection/correlation/rules`，窗口回测位于 `/detection/correlation/backtest`，归属“检测与情报 → 检测规则”。目录与结果分别使用一张业务表格，规则维护、修订查看和窗口证据使用弹窗。

## 功能范围

当前支持告警元数据的固定窗口 `count` 和 `distinct` 回测。保存规则或观察到阈值均不启动实时关联，不生成告警、模型研判、封禁授权或设备动作。结果中的 `source_coverage` 固定为 `not_attested`，`execution_authorized` 固定为 `false`。

以下能力仍须独立实现和验收：实时消费与状态恢复、事件时间水位、迟到证据修订、序列和负向匹配、多数据集关联、关联告警生成与抑制，以及生产规模下的效果与容量。回测通过不能作为这些能力已经交付的证明。

## 规则与修订

规则包含名称、维护说明、允许回测状态、告警过滤条件、分组字段、计量方式、窗口时长与阈值。过滤条件复用告警高级检索编译器；留空表示查询时间范围内的全部告警，语法错误包含行列位置。

分组可选择 `source.ip`、`destination.ip` 或 `rule.id`，始终附加接入探针及注册代次。两个探针即使观察到相同私网 IP，也不会在当前规则中合并计量。不同值字段可选择源／目的 IP、源／目的端口及规则 SID，必须与分组字段不同；计数模式不接受不同值字段。端口零值因当前元数据不能区分缺测与实际端口 0，按未知值处理。

保存要求管理员、CSRF、幂等键和期望修订。规则头、不可变修订及维护审计在同一 PostgreSQL 事务写入，禁止无变更保存和旧修订覆盖。未知提交保留原始输入与请求键，字段锁定后只能核对原提交；断网不能作为写入未发生的证明。

每租户最多保存 128 条规则，包含停用规则；最近 24 小时最多保存 2048 个修订。规则目录按 ID 升序分页，游标同时绑定租户、名称筛选、状态与页面容量。当前配置受引用保护；未被引用的历史修订按操作数据策略保留，默认 180 天，到期由维护任务清理。当前接口提供维护、停用和历史读取，未提供删除目录对象。

## 窗口与计量

查询采用 UTC 半开区间 `[start,end)`；界面按浏览器本机时区输入并明确转换。起止时间精确到整秒，开始不得早于 2000 年，结束不得晚于服务端当前时刻。历史时间范围可以较早，单次跨度最多一小时。

窗口为 15–3600 秒，按 Unix 时间的 UTC 固定边界对齐，阈值为 2–5000。每个窗口分别返回唯一告警数、计量值、计量字段未知数及状态：

| 状态 | 含义 |
| --- | --- |
| `threshold_observed` | 完整窗口内，已进入快照的事实达到阈值 |
| `threshold_not_observed` | 完整窗口内的已观察事实未达到阈值，不表示网络安全 |
| `partial_window` | 查询切断窗口边界，不计入阈值窗口数 |

分组字段缺失的告警单独计数，不构造虚假实体。相同事件身份且事实一致时不重复计量；相同身份对应不同事实时拒绝整个结果。Elasticsearch 快照读取层对重复文档、错误身份或不完整分页同样拒绝交付，不能把来源异常解释为业务去重成功。

## 来源、证据与限额

回测复用导出的 PIT 读取器，固定查询和排序，使用每页最新 PIT 身份及完整 `search_after`，检查分片、精确命中数、索引归属、租户、事件身份及半开时间范围，结束后释放 PIT。只读取元数据白名单，不读取原始 EVE、通信载荷或 PCAP。告警继续存储在 Elasticsearch；PostgreSQL 保存配置、修订和操作审计。

单次最多读取 5000 条告警、8 MiB 编码元数据及 512 个实体窗口分组。与检索导出共享每进程 2 项、每租户 1 项的读取额度；配置 Redis 时增加分布式租约，最长执行 50 秒。超限返回 413，额度忙碌返回 429；超时、撤权、停用、换版、来源异常、PIT 释放失败或审计失败均不返回部分结果。

窗口身份由租户、规则与修订、定义摘要、探针及注册代次、分组字段和值、窗口开始时间及阈值槽共同计算。证据集合摘要独立计算，包含窗口全部事实；同一窗口的补充事实不创建另一窗口身份。快照摘要绑定规则、查询与全部去重事实，不依赖临时 PIT 标识。

证据弹窗按事件 ID 排序展示最多 8 条样本，包含事件时间与原文 SHA-256。超过样本上限时明确标注截断，计量及集合摘要仍包含全部窗口事实。结果仅保留在当前页面会话中；操作审计记录读取动作，当前没有持久回测报告、后台作业或结果下载。

PIT 完整只表示此次检索快照满足读取契约，不证明捕获覆盖、无丢包、全量索引、水位完结或攻击成功。零命中、字段缺失、部分窗口和来源读取失败分别呈现，不能合并为安全结论。

## 权限与交互

管理员和只读账号可读取本租户规则及未过期修订；维护与窗口回测仅限管理员。历史修订可以核对，但执行必须使用当前允许回测的固定修订。分页读取、事实读取和结果交付前重新核对会话、账号及配置状态；停用或变更后不得继续使用旧修订。

修改查询、重选规则、切换账号或离开页面会取消等待并清除旧结论，迟到响应不会覆盖当前条件。“停止等待”只表示界面不再等待，不能宣称服务端已即时停止全部处理。复制失败明确提示手动复制，长标识与摘要自动换行，表格横向滚动限定在表格容器。

HTTP 契约见 [平台 OpenAPI](../api/openapi/platform.json)。原型使用合成固定快照和共享业务组件，不调用工程 API，不作为真实捕获或检测效果证据；工程证据须绑定实际冻结源码及原始测试记录。
