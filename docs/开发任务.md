## 已定的决策（2026-11-20）

| 事项 | 决定 |
| --- | --- |
| 配色 | 主色加深为靛蓝 `#2f54eb`；信息提示回灰底、指标数字用中性色、严重与高危分色、语义文字加深。取值见 [DESIGN.md](../DESIGN.md)「改版」 |

| 配置的位置 | 系统级配置（用户、AI 自动化级别、旁路阻断、全流量存储、探针健康阈值）集中在“系统设置”；业务页面只展示本页内容，只读显示当前值 |
| 用语 | 状态用语统一成标准词，登记在 `web/packages/shared/src/terms.ts`，对照表见 [DESIGN.md](../DESIGN.md)「用语」 |
| 分工 | 用 Claude 时：主会话做决策分析、文档和复核，代码改动交给子代理（Opus 5.5）。后续开发交给 Grok：它负责代码、测试和本文的进度记录，测试在远程主机执行。见[开发规范](开发规范.md)第 8 节 |
| 联动设备与联动插件 | 留在响应中心，不放进系统设置；系统设置只放参数、开关、策略和用户 |
| 原型与工程端 | 以设计规范为准，通用件收敛成 `web/packages/shared/` 里的一套共享组件 |
| 未提供的工作区 | 工程端侧栏隐藏，只在“系统设置”的功能目录里列出 |
| AI 自动化级别 | 仅观察、人机协同、条件自动、全自动四级，默认人机协同，见 [AI 自动化处置设计](AI自动化处置设计.md) |
| AI 助手 | 每个页面可唤起的侧边助手，加独立对话页；新增“AI 值守”页 |
| 联动插件 | 模板与脚本两种写法，采集器内运行，可由 AI 生成草稿，见[联动插件设计](联动插件设计.md) |
| 旁路阻断 | 内建，默认关闭，按策略授权开启，见[旁路阻断设计](旁路阻断设计.md) |
| 原包留存 | 默认智能留存，可切换完整保存或只存告警相关，见[全流量存储设计](全流量存储设计.md) |
| 索引存储 | 继续用 Elasticsearch（启用 logsdb 模式与索引排序），逐包位置放采集器本地分段索引；不引入 ClickHouse |
| 流程文档 | 以开发规范、测试与发布流程、开发任务三篇为准；旧流程文档归档到 `docs/archive/` |
| 截图图库 | 精简为约 190 张代表图，一键重拍，只在发版前重拍，不绑定源码摘要 |
| 源码格式 | 引入 Prettier（行宽 120），一次性全量格式化，CI 检查 |
| 深色主题 | 本轮不做；主题变量按浅色、深色两组取值的结构组织，只提供浅色 |
| 提交方式 | 直接提交到 `main`，一个条目一个提交；推送和打标签须经确认 |
| 测试位置 | 只在远程主机或 CI 执行；本机只做编译、静态检查和类型检查 |
