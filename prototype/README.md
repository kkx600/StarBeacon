# 星烽 StarBeacon 页面原型

Vue 3、TypeScript 与 Ant Design Vue 实现的交互原型。主控平台覆盖 42 个主导航工作区、121 个功能视图；采集器提供 5 个独立工作区。两种入口覆盖 107 项功能需求、756 个业务状态（主控 726 个、采集器 30 个）及 11 个登录／访问边界页面。全部记录为合成示例，表单提交仅改变浏览器内存中的示例数据，刷新后恢复初始内容。

## 查看原型图

直接用浏览器打开 [图片目录](public/screenshots/index.html)，按模块、页面名称、需求编号和页面状态筛选。每个业务页面提供有数据、无数据、查看详情、操作表单、加载中、加载失败六张完整图片。11 个边界页面单独列出，采集器独立归入“采集器管理”模块。

当前图库包含 767 张基础图（756 个业务状态与 11 个登录／访问边界）及 66 张补充图，合计 833 张。基础图库于 2026-10-13 通过内置浏览器重新采集，应用规则与协议能力六状态、部署表单、受理状态及采集器协议目录、详情、来源于 2026-10-14 实际采集。主控平台、采集器与原型共用控件主题：保留白色面板和纯浅灰工作区，使用中性文字、清晰的控件边界、蓝色主要动作及独立的焦点、错误和禁用状态。图片来自实际浏览器捕获；PNG 来源仅转码为 JPEG，不合成内容或调整历史图片颜色。注册与证书六状态、证书目录六状态及采集器身份状态于 2026-10-17 实际捕获。

来源、状态核对、实际视口、捕获时间、主题摘要和文件校验值记录在[截图来源清单](public/screenshots/provenance.json)。基础图覆盖有数据、无数据、详情、操作、加载与失败；补充图通过实际页签和表单操作展示通信证据、输入校验、规则错误、采集配置与授权详情。全部数据为合成示例，不代表实测性能或生产验收。

全部 124 个工作区的操作状态完成 1024×600 短屏 DOM 检查；七个代表表单另覆盖 390×844、768×900、1440×900、1920×1080 和 2560×1440，共 159 项记录。未发现整页横向溢出、弹窗越界或弹窗内容横向溢出；几何检查不代替所有页面逐图人工视觉和业务验收。

本地 HTML 目录可以离线查看图片；“交互页面”链接需要启动下面的服务。

## 启动交互页面

使用 Node.js 24.19.0 或更高的兼容版本、pnpm 12.6.0。本次构建实测环境为 Node.js 24.19.0。

```sh
pnpm --dir web install --frozen-lockfile
pnpm --dir prototype install --frozen-lockfile
pnpm --dir prototype dev
```

以上命令从仓库根目录执行。原型直接复用 `web/packages/shared` 的规则编辑器与工具源，先安装 `web` 是必要前提；无需启动 Go 或两个工程前端。原型与 `web` 各自保留锁文件，Vite 对 Vue 与 Ant Design Vue 去重。打开 `http://127.0.0.1:4173/`。完整页面目录位于 `http://127.0.0.1:4173/catalog`，图片目录位于 `http://127.0.0.1:4173/screenshots/index.html`。服务仅监听本机。

采集器管理入口为 `http://127.0.0.1:4173/collector/network`，本地登录入口为 `/collector/auth/login`；采集器图片可通过 `/screenshots/index.html?module=collector` 筛选。主控平台探针详情“采集与版本”页签提供同一合成样机的“采集器本地管理”入口。原型共用开发服务，生产需分别构建、部署和鉴权，见[采集器管理与部署设计](../docs/采集器管理与部署设计.md)。

顶栏的“原型状态”下拉是原型评审工具。它可直接打开详情、操作、空状态和异常状态，不属于正式生产页面的业务权限。URL 示例：`/page/alerts?state=detail`。

导航按照工作任务组织，相关对象通过工作区页签进入，详情以弹窗呈现；完整需求与路由映射见[页面原型设计](../docs/页面原型设计.md)。旧探针运行状态、PCAP 下载和重复操作日志地址保留兼容跳转。

路由使用 History 模式，迁移旧 `#/` 地址并保留查询参数。检测规则工作区的「重放样本」与「重放任务」分别为 `/page/rule-samples`、`/page/rule-tests`。采集器网络页使用 `view=capture`／`replay-samples`／`replay-tasks`，规则与升级页的系统升级使用 `view=system`，维护页的操作日志使用 `view=audits`；缺失或非法 view 回到所属工作区默认页签，切换页签可通过刷新、后退和前进恢复。

## 交互范围

| 工作域 | 原型可操作内容 |
| --- | --- |
| 通用列表 | 可见字段关键词筛选、状态／网络域筛选、排序、分页、列显示、选择记录、详情、表单校验、批量本地修改、CSV／JSON 导出 |
| 高级检索 | 支持清单中的事件字段比较、集合、CIDR、协议存在、布尔组合；未知字段及未实现语义明确报错；结果为本地合成记录；导出弹窗冻结示例结果，CSV 上限 10,000 条／8 MiB，包含公式防护与长整数文本，不创建真实 PIT |
| 协议能力 | 独立展示识别、事务与日志、在线规则、文件提取、报文取证与外部补充，目录筛选、来源摘要、分层详情及限额；全部为合成观测，不代表引擎实际配置或效果资格 |
| 通信证据 | 数据包列表、协议树、TCP 标志、实际示例 MAC、时间字段、HEX／UTF-8／ASCII 展示、字节选择与偏移定位 |
| 规则工作台 | 自然语言、HTTP Raw 和样本文件名输入；共享 CodeMirror 高亮、行号与基础结构诊断；展示固定候选、合成验证结果和发布路径，不执行真实模型或 Suricata |
| 应用识别规则 | 产品、类别、协议与三组条件，复用工程表单和输入验证弹窗；目录、修订、名称匹配、单探针部署与受理状态均为内存合成示例，不请求工程服务；结果保留未知、候选和不同产品冲突 |
| 重放样本与任务 | 平台和采集器分视图展示样本、规则编辑、任务及合成结果；一个视图对应一个业务数据集，不上传样本、不执行引擎 |
| 智能助手 | 本地示例回复、证据引用和工具轨迹；不调用远程模型或 MCP 服务 |
| 研判处置确认 | 评估详情进入独立确认弹窗，原源 IP 只读，探针、连接器、期限与依据校验；只保存当前弹窗中的示例授权，不调用工程服务或生成设备任务 |
| 自动化响应 | 策略门槛、审批／自动／影子模式、执行采集器、设备回执、撤销状态、剧本节点；不访问设备 |
| 留存治理 | 默认 180 天、分类期限、变更依据、影响确认、保全排除、无压缩容量估算；不执行数据删除 |
| 事件与报告 | 案件时间线、任务、笔记、告警关联、报告正文与导出路径 |
| 探针管理 | 统一设备列表，连接和健康筛选、资源与捕获指标、同一探针详情、阈值配置；离线遥测不可观测，执行角色不计入捕获流量 |
| 采集器管理 | 本机状态、管理网卡与镜像网卡、地址与采集参数、平台接入、注册密钥、证书、同步设置、升级和规则回滚、维护与审计；提交仅创建待执行任务，实际配置保持不变 |
| PCAP 取证 | 平台展示会话完整性、导出结果、文件与授权；采集器展示本机捕获／确认目录，未封存计数保持缺测，平台确认回收后引导在平台查看完整清单；合成数据不提供真实 PCAP 下载 |
| 运营控制台 | 概览图表、拓扑节点查看、大屏、探针与平台运行示例、多租户配置、审计和通知记录 |

文件选择只显示样本文件名，不读取或上传文件。浏览器内存中的表单数据不写入数据库或远程服务。原型不会提供真实 PCAP 下载、身份认证、模型推理、沙箱执行、规则验证、邮件发送或防火墙写入。

规则编辑器本地检查受控 `alert` 规则的基本结构、SID 范围／重复及 rev 等字段，错误可定位；它不解析完整 Suricata 语义。关键词、变量和引擎兼容性仍须在工程中由指定探针执行原生 `-T`。容量与速率显示复用共享数量工具，保留大计数精度，并区分 SI、显式二进制单位和缺测。

置信度内部单位统一为 0–1，列表、详情和 CSV 使用百分比展示；例如保存 `0.97` 后显示 `97%`。策略运行模式与生命周期状态分开。通信原包仅展示明确绑定的示例会话，其他记录保留证据缺口。

## 验证与构建

```sh
cd prototype
pnpm check:coverage
pnpm check:workspaces
pnpm check:collector
pnpm check:theme
pnpm build
pnpm preview
```

覆盖脚本核对页面与功能矩阵的编号、重复路由和必要配置，并生成图片目录的页面清单。构建包含 TypeScript 与 Vue 模板检查。配色脚本核对 54 组正文与业务文字组合的对比度不低于 4.5、18 组选择标记、焦点与图形组合不低于 3，并检查静态目录颜色与主题一致；普通输入轮廓、占位提示和参考图的亮蓝主按钮分别记录实测对比度，不计入正文 AA 范围；不宣称全页面无障碍验收。截图文件核对脚本检查全部状态文件、JPEG 格式和来源校验值。

```sh
node scripts/check-screenshots.mjs
```

正式工程的 `/traffic` 提供协议事件与会话摘要检索，包括实际双向计数、会话时间、MAC 集合和 TLS／DNS 展示；原型中的应用流重组与应用品牌识别仍属于目标设计。独立原包捕获、归档、有界逐包协议查看和会话导出已具备工程子流程，不表示海量取证、全部协议或生产资格已经交付。实际入口与数据边界见[流量检索与会话观测](../docs/流量检索与会话观测.md)。

原包归档的「协议查看」使用独立弹窗展示固定九帧 HTTP 合成样本，包含序号翻页、MAC／IP／TCP 字段、纳秒时间及 HEX／UTF-8；样本字节与协议字段由实际测试 PCAP 和 gopacket 生成，弹窗明确标识合成来源，不读取列表记录的实际原文。平台已归档行可查看，采集器仅等待上传行可查看；已回收、捕获中和待核查原件禁用该操作。工程两端已有有界逐包读取接口，范围和限制见[原包归档与会话导出](../docs/原包归档与会话导出.md)。此交互未生成对应截图，不替代真实网卡或对象存储验收。

覆盖映射表示需求已有页面入口和示例交互，不表示后端、协议引擎、连接器、权限或容量已经实现或验收。生产功能、接口和部署约束仍以仓库产品设计及工程设计为准。

全部 833 张图片通过 JPEG 格式、实际视口、来源与 SHA-256 核对。检测质量的区间观测、尚未观测、计数复位、过期、离线及刷新失败六张补充图于 2026-10-17 通过可见控件实际捕获，使用明确标识的合成数据；协议能力与采集器网络页面的十二张基础状态图与当前入口一致。人工视觉检查覆盖列表、决策表单、通信证据、规则编辑器和采集器操作；截图数量不等于逐图人工视觉验收。图库通过 HTTP 服务查看，内置浏览器不使用本地文件协议。

## 文件组织

- `src/data/catalog.ts`：页面名称、路由、需求编号、表格列、表单字段和业务提示。
- `src/data/fixtures.ts`：合成业务记录；缺失或未知证据保留明确状态。
- `src/data/collector.ts`、`src/composables/useCollector.ts`：采集器样机、配置检查和待执行任务；不调用真实设备。
- `src/views/`：概览、检索、规则、助手、留存、剧本、拓扑、大屏等独立工作区。
- `src/components/`：通用列表、表单、详情、通信证据与状态组件。
- `src/theme.ts`：重新导出工程共享主题；`web/packages/shared/src/controls.css` 提供三端一致的控件和弹窗样式。
- `public/screenshots/`：全部状态图片、补充图片、图片目录与来源清单。
- `public/page-manifest.json`：可机读的页面、状态和需求映射。
- `scripts/`：覆盖与图片完整性核对。

布局参考 [Soybean Admin Ant](https://github.com/soybeanjs/soybean-admin-antd) 与[其产品介绍](https://admin-docs.soybeanjs.cn/guide/intro)，采用本仓库业务字段和交互实现。组件使用依据来自 Vue、Ant Design Vue、Vue Router 与 ECharts 官方文档，经 Context7 查询核对。

颜色、字体、组件与业务状态的一致性约束见[界面设计规范](../DESIGN.md)。

配色由 `src/theme.ts` 统一定义，白色面板与纯浅灰工作区（`#f7f7f7`）承载内容，亮蓝用于主操作，绿色、琥珀色和玫红分别表达正常、关注与风险。状态保留文字说明；指标保持白色背景，以数值和文字颜色表达状态；图表使用蓝、青、紫和橙色，大屏使用独立深灰底与高亮蓝青色。挂载到 `body` 的弹窗、通知和下拉控件继承同一套根级颜色变量。

“AI 规则生成”输入、候选和详情遵循[AI 规则生成与样本验证](../docs/AI规则生成与样本验证.md)：检测说明适用于所有材料来源，HTTP Raw 明确为合成 TCP 流，材料提取有界且不解密 TLS，单次数据使用许可、生成候选与正式发布分别呈现。原型使用固定合成数据，不代表模型或原生引擎已经执行。

探针管理工作区包含探针列表和探针分组两张独立页签。管理表单展示名称、归属、站点、说明和独立修订；分组停用前检查成员数量。原型数据及成员数量均为合成示例，不表示实际注册、权限授权或设备运行结果。原包归档与探针分组的十二张状态图可在图片目录按页面名称查看；独立评估记录另有六张状态图。

## 联动设备

采集器“网络与采集 → 联动设备”提供加载、错误、空状态、设备目录、详情与配置说明。目录和设备回读均使用合成示例，控制台不提供设备写入入口；平台探针详情区分管理员手动任务与影子模型评估，不把受理或回读直接描述为流量阻断。当前联动原型六种状态完成八档 PC 宽度和两个 1024×600 弹窗共 50 项稳定 DOM 核对；旧页视口设置失败独立保留，后续通过观察使用实际生效的新建内置浏览器页面绑定。此记录不代表全原型逐图视觉验收。工程协议与边界见[HTTP 联动与限时封禁](../docs/HTTP联动与限时封禁.md)。
