# 星烽 StarBeacon 页面原型

Vue 3、TypeScript 与 Ant Design Vue 实现的交互原型。主控平台设计目录包含 44 个主导航工作区、130 个功能视图，采集器提供 5 个工作区、9 个规范功能视图。原型映射 107 项功能需求，使用合成示例。表单提交仅更新浏览器内存，刷新后恢复初始内容。

工程平台登记 51 个业务视图，覆盖 30 个工作区。其余 14 个工作区在系统设置的功能目录标明交付状态。部分原型设计视图的工程能力通过弹窗或页签提供。[功能实现与验收状态](../docs/功能实现与验收状态.md)

联动设备目录和采集器配置核对使用工程端相同的筛选、列表、详情、限时封禁表单与配置结果组件。主控平台的设备动作由平台提交，采集器本地核对仅比较固定文件与运行绑定；全部原型数据明确为合成示例。设备目录按探针、设备关联至响应动作，详情与限时封禁绑定同一连接器配置。

## 启动交互页面

使用 Node.js 24.19.0 或更高的兼容版本、pnpm 12.6.0。本次本机构建环境为 Node.js 24.19.1。

```sh
pnpm --dir web install --frozen-lockfile
pnpm --dir prototype install --frozen-lockfile
pnpm --dir prototype dev
```

以上命令从仓库根目录执行。原型直接复用 `web/packages/shared` 的规则编辑器与工具源，先安装 `web` 是必要前提；无需启动 Go 或两个工程前端。原型与 `web` 各自保留锁文件，Vite 对 Vue、Vue Router 与 Ant Design Vue 去重。打开 `http://127.0.0.1:4173/`。完整页面目录位于 `http://127.0.0.1:4173/catalog`，图片目录位于 `http://127.0.0.1:4173/screenshots/index.html`。服务仅监听本机。

采集器管理入口为 `http://127.0.0.1:4173/collector/overview/status`，本地登录入口为 `/collector/auth/login`；采集器图片可通过 `/screenshots/index.html?module=collector` 筛选。主控平台探针详情“采集与版本”页签提供同一合成样机的“采集器本地管理”入口。原型共用开发服务，生产需分别构建、部署和鉴权，见[采集器管理与部署设计](../docs/采集器管理与部署设计.md)。

顶栏的“原型状态”下拉是原型评审工具。它可直接打开详情、操作、空状态和异常状态，不属于正式生产页面的业务权限。URL 示例：`/alerts/list?state=detail`。

导航按照工作任务组织，相关对象通过工作区页签进入，详情以弹窗呈现；完整需求与路由映射见[页面原型设计](../docs/页面原型设计.md)。

路由使用 History 模式。检测规则工作区的「重放样本」与「重放任务」分别为 `/detection/rules/samples`、`/detection/rules/tasks`；页面目录与内部链接使用的 `/page/rule-samples`、`/page/rule-tests` 跳转至这些规范路径并保留查询参数。采集器规范路径按运行状态、网络与采集、平台接入、规则与任务、联动设备组织，分别提供 `/collector/overview/status`、`/collector/network/interfaces`、`/collector/network/capture`、`/collector/network/archives`、`/collector/network/syslog`、`/collector/connection/identity`、`/collector/rules/samples`、`/collector/rules/tasks`、`/collector/response/devices`。采集器原型的旧工作区与查询链接仍保留兼容跳转；管理网络、编辑接入密钥、集中同步、系统升级与维护的目标设计在上下文中明确区分，不能作为工程可操作能力。刷新、后退和前进恢复规范路径。

| 采集器管理 | 九个规范视图对应本机状态、网卡、采集、归档、Syslog、只读通信身份、样本、任务和联动设备；页面使用合成数据。管理网络生效／回退、接入密钥编辑、系统／引擎升级和维护 Web 属于目标设计，不能据此认为工程已有对应执行能力 |

| 运营控制台 | 概览图表、拓扑节点查看、大屏、探针与平台运行示例、多租户配置、审计和通知记录 |

文件选择只显示样本文件名，不读取或上传文件。浏览器内存中的表单数据不写入数据库或远程服务。原型不会提供真实 PCAP 下载、身份认证、模型推理、沙箱执行、规则验证、邮件发送或防火墙写入。

规则编辑器本地检查受控 `alert` 规则的基本结构、SID 范围／重复及 rev 等字段，错误可定位；它不解析完整 Suricata 语义。关键词、变量和引擎兼容性仍须在工程中由指定探针执行原生 `-T`。容量与速率显示复用共享数量工具，保留大计数精度，并区分 SI、显式二进制单位和缺测。

置信度内部单位统一为 0–1，列表、详情和 CSV 使用百分比展示；例如保存 `0.97` 后显示 `97%`。策略运行模式与生命周期状态分开。通信原包仅展示明确绑定的示例会话，其他记录保留证据缺口。

### 重拍图库

在验收机按启动步骤安装 `web` 和 `prototype` 的锁定依赖，并准备 Chrome 与简体中文字体。从仓库根目录执行下列命令。

```sh
pnpm --dir prototype screenshots:capture
```

命令生成原型页面清单、构建原型并在回环地址启动预览。Playwright Core 使用无头浏览器捕获实际组件渲染，核对页面状态后保存原生 JPEG。浏览器版本、路由、状态和文件名随截图写入清单。脚本在整批校验后替换图库并移除清单外的图片。使用其他 Chromium 时，可通过 `STARBEACON_CHROMIUM_EXECUTABLE` 指定可执行文件路径。

`pnpm --dir prototype check:screenshots` 只读取图库的两份清单与图片，核对清单一致、文件齐全和尺寸为 1440×900。图库用于检查原型界面与示例状态。

正式工程的 `/traffic/events` 提供协议事件与会话摘要检索，包括实际双向计数、会话时间、MAC 集合和 TLS／DNS 展示；原型中的应用流重组与应用会话流量排行仍属于目标设计。应用识别规则已有受限可见元数据分类子流程，不能等同完整产品效果。独立原包捕获、归档、有界逐包协议查看和会话导出已具备工程子流程，不表示海量取证、全部协议或生产资格已经交付。常驻验收实例未启用持久托管采集，实际入口与数据边界见[流量检索与会话观测](../docs/流量检索与会话观测.md)。

原包归档的「协议查看」复用工程 PacketInspector，独立弹窗显示九帧 HTTP 合成样本，支持翻页、协议字段、纳秒时间、HEX 与 UTF-8。平台已归档记录和采集器等待上传记录可进入协议查看。工程逐包读取接口的范围见[原包归档与会话导出](../docs/原包归档与会话导出.md)。

工程功能、权限及运行条件见[功能实现与验收状态](../docs/功能实现与验收状态.md)。历史图库的来源及检查结果保存在[归档的验收记录](../docs/archive/测试覆盖与验收记录.md)。

## 文件组织

- `src/data/catalog.ts`：页面名称、路由、需求编号、表格列、表单字段和业务提示。
- `src/data/fixtures.ts`：合成业务记录；缺失或未知证据保留明确状态。
- `src/data/collector.ts`、`src/composables/useCollector.ts`：采集器样机、配置检查和待执行任务；不调用真实设备。
- `src/views/`：概览、检索、规则、助手、留存、剧本、拓扑、大屏等独立工作区。
- `src/components/`：通用列表、表单、详情、通信证据与状态组件。
- `src/theme.ts`：重新导出工程共享主题；`web/packages/shared/src/controls.css` 提供三端一致的控件和弹窗样式。
- `public/screenshots/` 保存代表图、可离线浏览的图片目录和两份图库清单。
- `public/page-manifest.json`：可机读的页面、状态和需求映射。
- `scripts/`：覆盖与图片完整性核对。

布局参考 [Soybean Admin Ant](https://github.com/soybeanjs/soybean-admin-antd) 与[其产品介绍](https://admin-docs.soybeanjs.cn/guide/intro)，采用本仓库业务字段和交互实现。组件使用依据来自 Vue、Ant Design Vue、Vue Router 与 ECharts 官方文档，经 Context7 查询核对。

颜色、字体、组件与业务状态的一致性约束见[界面设计规范](../DESIGN.md)。

三端使用共享主题，白色面板与浅灰工作区（`#f4f4f4`）承载内容，按钮与记录链接使用靛蓝 `#2f54eb`。页面通过共享分页、状态标签和标题旁的「?」说明当前业务口径。原型的系统设置集中演示自动处置、旁路阻断、全流量存储和探针健康阈值，业务页摘要显示相关配置。AI 值守、联动插件、旁路阻断、全流量回溯和全局 AI 助手都可在原型操作。自动化编排对应原型中的「响应剧本」，支持按类型配置步骤和采纳 AI 草稿。

“AI 规则生成”输入、候选和详情遵循[AI 规则生成与样本验证](../docs/AI规则生成与样本验证.md)：检测说明适用于所有材料来源，HTTP Raw 明确为合成 TCP 流，材料提取有界且不解密 TLS，单次数据使用许可、生成候选与正式发布分别呈现。原型使用固定合成数据，不代表模型或原生引擎已经执行。

探针管理工作区包含探针列表和探针分组两张独立页签。管理表单展示名称、归属、站点、说明和独立修订，分组停用前检查合成成员数量。图库提供探针列表、探针分组和原包归档的有数据状态。其他状态可通过原型顶栏切换。

## 联动设备

采集器“联动设备”提供加载、错误、空状态、设备目录、详情与配置说明。目录和设备回读均使用合成示例，控制台不提供设备写入入口；平台探针详情区分管理员手动任务与影子模型评估，不把受理或回读直接描述为流量阻断。当前联动原型六种状态完成八档 PC 宽度和两个 1024×600 弹窗共 50 项稳定 DOM 核对；旧页视口设置失败独立保留，后续通过观察使用实际生效的新建内置浏览器页面绑定。此记录不代表全原型逐图视觉验收。工程协议与边界见[HTTP 联动与限时封禁](../docs/HTTP联动与限时封禁.md)。
