# 星烽 StarBeacon 前端工程

`platform` 为主控平台，`collector` 为采集器本地管理，两者是独立构建、独立登录和独立 API 命名空间。`packages/shared` 复用经确认的白灰背景、蓝色动作、4/8/12/16 px 间距和 Ant Design Vue 组件。交互原型继续位于仓库根目录 `prototype`，正式工程不加载合成数据或原型状态开关。

## 组件职责

| 组件／模块 | 单一职责与数据契约 |
| --- | --- |
| App / 路由视图 | 配置主题、布局及业务组件，不持有表单、表格或请求实现。 |
| AppShell | 接收菜单、用户名、当前路由和平台密码入口权限，发出导航、退出及密码维护事件；窄屏折叠导航。 |
| LoginForm | 接收提交状态和错误，校验并发出账号密码提交事件；不持有凭据存储。 |
| useSession / ApiClient | 管理 HttpOnly 会话查询与内存 CSRF Token，统一错误和取消信号。 |
| SensorsWorkspace / useSensors | 获取当前租户分页探针与健康快照，编排单表页签、详情、分组筛选和启用状态操作。 |
| GroupTable / ManagementForm / useSensorGroups / useSensorMutation | 分组单表与独立管理弹窗、完整启用分组选项、注册代次与管理修订、冻结原提交及人工确认。 |
| SensorTable / SensorDetail | 接收真实探针数据，分别发出查看／编辑／状态操作事件和展示实际部署与观测详情。 |
| CaptureDialog | 冻结目标注册代次、实际网卡及采集修订；校验后下发签名任务，失败保留草稿与原幂等键。 |
| AlertsWorkspace / useAlerts | 管理有界服务端检索、分页和请求取消；不使用本地全量筛选。 |
| AlertFilters / AlertTable / AlertDetail | 分别接收条件并发出查询、展示分页记录、展示当前记录及原始 EVE。 |
| AdvancedFilter | 按告警／协议事件数据集读取服务端字段目录，提供类型化表达式与错误位置。 |
| TrafficWorkspace / useTraffic | 独立协议记录检索，完整分页校验、查询取消及固定窗口；错误不显示为空列表。 |
| TrafficFilters / TrafficTable / TrafficDetail | 条件表单、一张流量列表、实际会话计数／时间／MAC／TLS／DNS 详情及权限限制。 |
| PacketArchiveWorkspace / usePacketArchives / PacketArchiveDetail | 平台游标目录、采集器有界暂存目录、真实编码／捕获元数据、完整摘要核验和下载。 |
| SessionExportDialog | 平台选择同源切片、固定双端 IP／端口／MAC／VLAN，明确完整会话或快照模式；失败展示真实缺口，不隐式降级。 |
| ByteViewer | 对 EVE 载荷副本或已核验原始捕获帧做有界 HEX／UTF-8 查看、偏移分页与复制；来源分别标识，不生成缺失原包。 |
| InventoryWorkspace / useInventory | 资产、资产组、网段单表页签、编辑校验、不可变修订与历史弹窗。 |
| OperationsWorkspace / useAudits | 运行状态、操作日志与登录日志分别展示，审计使用稳定游标。 |
| NotificationsWorkspace / useNotifications | 渠道与推送日志分离，配置凭据只写，未知结果人工核对，Syslog 按告警、操作日志与登录日志配置订阅，展示日志类别、记录数量与完整写入帧数；凭据和操作原因不外发。 |
| ModelsWorkspace / useModels | 加密配置、凭据保留／替换／清除、成本提示及有限连接验证；用量缺失不补零。 |
| OverviewWorkspace / useOverview | 完整统计、固定窗口下钻、有界刷新与全屏，失败不补零。 |
| AssistantWorkspace / useAnalysis | 私有对话、冻结统计来源、精确幂等确认、取消与未知结果反馈。 |
| ReportsWorkspace / ReportPlansWorkspace / AnalysisDetail | 报告记录、计划和运行记录独立单表视图，周期生成和配置弹窗、统计与模型结果分离、结果刷新及认证 HTML 下载。 |
| IncidentsWorkspace / useIncidents | 单事件列表、来源核验、责任分派、修订调查、结构化结案、重开及原提交核对。 |
| UsersWorkspace / useUsers | 本租户单表目录、创建、公开详情、权限编辑与独立成员密码重置。 |
| PasswordDialog / usePasswordChange / PasswordForm | 读取公开修订、校验操作者原密码与新密码字节、冻结原提交、明确确认未知结果；身份变化清理内存凭据。 |
| RetentionWorkspace / useRetention | 十一类保留策略、未来对象影响预览、发布确认及未知结果原提交核对。 |
| CollectorWorkspace / useCollector | 获取本机健康、网卡和目标配置，编排配置保存，不调用操作系统网络变更。 |
| RulesWorkspace / RuleReleaseDialog | 不可变规则修订、选定探针装载与正反样本检查、固定修订发布、回滚和中断核实；受理与生效分别呈现。 |
| ApplicationRulesWorkspace / ApplicationRuleForm / ApplicationRuleTest | 应用识别规则单表目录、不可变修订、条件表单与材料验证；名称候选、未知和冲突不代表真实流量归因或产品准确率。 |
| RuleGenerationWorkspace / useRuleGeneration | 有界材料、当前模型修订与单次许可，私有历史、冻结请求确认、候选高亮、取消和精确采纳。 |
| RuleEditor / inspectRules | 共用 CodeMirror 6 编辑器，提供行号、高亮、撤销、换行和基础结构错误定位；关键词、变量与引擎兼容由原生 Suricata 检查。 |
| ReplayWorkspace / ReplayResult | 两端 PCAP / HTTP Raw 原字节导入、合成来源提示、规则与执行探针选择、真实离线结果及失败／截断边界。 |
| TaskWorkspace / TaskTable | 平台签名任务、独立本地任务、任务标识链接、原档案单条读取、执行时回执及有限刷新；历史核实摘要不冒充设备当前状态，装载回执不推断后续样本状态。 |
| HealthSummary / InterfaceTable | 展示实测指标、网卡能力和观测时间；离线及缺测保留明确状态。 |
| CaptureForm / CaptureResult | 两端共享采集参数表单与执行时回执描述；本机保存、平台受理、生效修订和回执观测时间分别呈现，当前状态在采集配置中核对。 |

## 界面边界

流量检索 `/traffic?view=events` 对管理员和只读账号开放，边界见[流量检索与会话观测](../docs/流量检索与会话观测.md)。原包归档为 `/traffic?view=archives`，仅管理员可访问。采集器原包暂存位于 `/network?view=archives`，各视图只展示一份业务列表。

两端原包列表的「协议查看」打开一个弹窗，支持上一包、下一包及序号跳转。回执必须绑定归档、目录摘要、所选包序号、捕获时间范围及原始帧 SHA-256，再展示最多 16 层协议字段与 HEX／UTF-8。详情保留纳秒 UTC 时间；截断、VLAN 卸载和解析预算独立标注，不推断入站／出站时间、应用重组、报文校验和或 TLS 明文。切换、请求失败及关闭均清除旧字节，迟到响应不能恢复内容；弹窗使用有界内部滚动，不增加第二张业务列表。本机已确认上传并回收原件的行禁用查看，实际原件在平台读取。

采集器原包目录区分正在捕获、未封存的中断原件与完整归档。开始记录只核验身份、网卡、配置和暂存预留；包数、首尾包时间及完整性计数显示「尚未冻结」，不能把开始记录中的空值解释为零流量或零丢包。未封存记录不能下载或导出完整通信；完整目录与文件摘要仍须独立核验。

平台 `/sensors` 通过「探针列表」「探针分组」与「任务记录」页签组织目录和任务，`view=devices`／`groups`／`tasks`；`/rules` 通过「规则包」「重放样本」「重放任务」页签分别展示数据，`view=packages`／`samples`／`tasks`。采集器 `/network` 分为「网卡与状态」「采集配置」「重放样本」「任务记录」，`view=interfaces`／`capture`／`samples`／`tasks`。资产管理 `/assets` 使用 `view=assets/groups/networks`；运行与审计 `/operations` 使用 `view=health/operations/logins`；通知中心 `/notifications` 使用 `view=channels/deliveries`；模型配置为 `/models`，智能助手为 `/assistant`，报告中心为 `/reports`（`view=records/plans`），态势总览／全屏分别为 `/overview`／`screen`，数据留存为 `/retention`。运行与审计、通知中心、模型配置、智能助手、报告中心和数据留存仅对管理员开放。每个视图只展示所属业务数据集，详情描述表不作为另一份业务列表。

页面使用中文业务名称，加载、错误、无数据各自呈现真实请求状态；数据缺测使用“未获取”。探针在线状态以平台接收时间判定，离线后保留最后观测时间。CPU、内存、磁盘和网络计数标注宿主机口径，接口字节数不作为镜像捕获吞吐。

原始 EVE 属于事件 JSON，不标为原生通信报文，不构造 PCAP、握手、攻击成功或封禁成功。原包归档另行读取独立捕获的 PCAPNG；导出仅复制匹配原始帧，模式和缺口分别标注。模型配置与连接验证不授予安全决策资格。尚未连接的升级、领域评测、报告审批发布／PDF 和设备阻断不提供可提交的假操作入口。

告警详情中的「告警研判」提供管理员人工结论、状态、依据、认领及历史。历史使用独立视图的一张列表；并发冲突需要刷新，未知保存冻结输入与原请求键，确认结果后才恢复操作。人工结果不抑制规则或触发封禁，边界见[告警研判与协作](../docs/告警研判与协作.md)。

同一详情中的「模型研判」提供单告警提交、历史选择、实际事实引用与材料限制。未知提交冻结输入及关闭，确认继续使用原请求键；活动作业有界轮询，取消不宣称提供方停止处理。模型自评分与处置建议均需复核，见[告警模型研判](../docs/告警模型研判.md)。

智能助手发送前逐次确认统计上下文，服务器只提交白名单统计。报告按指定时区的已结束自然日／周／月生成，支持纯统计报告和有限模型分析；结果未知时保留原始输入与幂等键，需用户主动确认，取消不保证模型未计费。列表和对话响应缺字段时保留上次有效记录并显示错误，下载失败不会触发保存。

PCAP 重放不向真实网络发包，本地输入规则与平台规则包修订分开标识；检测结果首屏呈现结论和包数／命中数／耗时。读取失败保留错误和重试，展示旧任务状态时明确提示尚未更新。具体部署及样本边界见[PCAP 重放与规则验证](../docs/PCAP重放与规则验证.md)。

规则编辑器仅对受控 `alert` 规则做本地基础诊断：规则头、引号／转义、括号结构、末尾分号、SID 范围与重复、rev 和 900 KiB 文本上限。错误项可点击定位；基础检查通过不表示完整 Suricata 语法、语义或目标引擎兼容已经验证。`rules.apply` 需要同一探针与配置的一天内原生装载、独立正反样本回执；缺少资格返回 409。

容量按 SI 的 B／KB／MB／GB／TB 等单位展示，速率按千进制 bit/s 系列展示；显式二进制值保留 KiB 等单位。累计整数字符串与 bigint 保留 64 位精度，缺测与零分开，带不同单位的数量按原始精度排序。

共享入口只注册通用 Ant 组件，业务组件及其子组件必须有明确的局部绑定。回归测试编译核对全部工程 Vue 模板的组件解析，同时检查导出弹窗的实际对话框、遮罩和页面外挂载；文案出现在 DOM 中不能作为组件渲染正确的证明。

## 路由与部署

两端使用 `createWebHistory(import.meta.env.BASE_URL)`，保留 `#/` 旧地址迁移、同源安全回跳及登录前完整路径，未知路径进入 404。工作区页签由查询参数确定，支持刷新与浏览器历史恢复。

Go API 不提供前端静态页。Vite 开发服务分别把 `/api` 代理到 28080／28081，生产需同源静态入口。[平台 Nginx 示例](../deploy/nginx/platform.conf)与[采集器 Nginx 示例](../deploy/nginx/collector.conf)将 `/api/` 代理、`/assets/` 404 和 SPA `index.html` 回退分开，配置 100 MiB 上传和 360 秒代理期限。两个示例均为 `listen 80`、`server_name _`，应在各自部署位置配置实际主机名／监听入口及 HTTPS；不能原样作为同一监听入口的两份默认站点。Go 的 `SB_ALLOWED_ORIGIN` 须设为该端实际外部来源（无路径，生产为 HTTPS），代理保留浏览器原始 Origin。示例配置不代表生产 TLS 或代理部署已经验收。

## 启动

使用 Node 24.19.0、pnpm 12.6.0。在仓库根目录执行：

```sh
pnpm --dir web install --frozen-lockfile
pnpm --dir web --filter @starbeacon/platform dev
pnpm --dir web --filter @starbeacon/collector dev
```

两条 dev 命令分别运行于不同终端，平台端口为 5174，采集器端口为 5175；Go 与开发依赖启动见[工程实现与开发](../docs/工程实现与开发.md)。检查与构建使用 `pnpm --dir web test`、`pnpm --dir web typecheck`、`pnpm --dir web test:coverage`、`pnpm --dir web build`。`python3 scripts/check_alignment.py --check` 核对工程路由是否全部进入验收清单；原型覆盖不等同工程功能或七档 PC 全路由交互通过。逐项状态见[功能实现与验收状态](../docs/功能实现与验收状态.md)。

共享包直接锁定 CodeMirror view 6.43.13、state 6.7.6、language 6.12.4、lint 6.9.7、commands 6.11.1 及 Lezer highlight 1.2.5。`prototype/` 直接引用共享源，启动／构建原型前也必须先安装 `web` 依赖；这项源码复用不要求工程应用进程同时运行。

数据留存用单表和配置弹窗展示真实类别范围，发布前必须核对影响预览并确认。既有对象的期限保持原值；连接中断或发布超时保留精确原提交，禁止自动更换幂等键重试。延长不能恢复已删除数据，也不保证立即释放存储空间。

报告计划按日、周、月和 IANA 时区配置；选择模型后须明确持续调用授权并固定修订。模型修订变化撤销旧勾选。保存响应未知时冻结原请求，通过确认操作核对精确输入；准备和最终报告状态分开显示。刷新失败保留旧运行记录，已经到期的报告不提供查看入口。边界见[报告计划与调度](../docs/报告计划与调度.md)。

AI 规则生成通过 `/rules?view=generation` 提供单表历史和操作弹窗；候选、帧摘要与风险通过详情展示，不与规则包列表同时呈现。详情保留 HTTP Raw 合成标识，未确认的提交使用原请求键核对。边界见[AI 规则生成与样本验证](../docs/AI规则生成与样本验证.md)。

用户管理通过 `/users` 提供本租户单表目录、创建、公开详情及权限编辑弹窗。创建及密码维护的凭据仅存在于对应表单与未确认请求的页面内存，身份改变或页面卸载时清理；原请求确认使用相同输入与键，不能在超时后自动再创建。修改权限或使用状态会撤销目标账号全部旧会话，当前管理员保护和 CAS 仍由后端核验。字段、额度与留存见[用户管理与权限](../docs/用户管理与权限.md)。

平台顶栏“修改密码”对管理员与只读用户开放；用户详情“重置密码”仅针对其他本租户成员。两种弹窗分别为 560px，保持一份操作表单；空字段、字节限制与确认不一致使用中文错误并取得焦点。成功修改自身密码返回登录入口，重置其他成员不注销操作者。采集器顶栏不显示尚未实现的本机密码维护入口。

探针管理默认每页 20 项，支持名称／标识／站点、分组和连接状态筛选；分组成员链接返回带条件的探针列表。各任务选择器读取完整分页目录，拒绝不完整选项。管理弹窗分别维护分组或探针名称、归属、站点、说明，使用独立管理修订和注册代次；未知结果保留原输入与请求键，身份变化清除草稿。分组不改变采集或响应权限，详见[探针分组与管理信息](../docs/探针分组与管理信息.md)。

## 前端依赖许可

生产构建包含 `dist/third-party-licenses.json`，记录实际打包依赖的许可原文与摘要；精确版本的上游补充来源见 [前端依赖许可](licenses/README.md)。`test` 与 `test:coverage` 均执行许可边界测试，Linux 包校验器核对项目许可及前端目录。该目录不替代完整 SBOM 或 Go 依赖通知。

平台任务链接为 `/sensors?view=tasks&task=<任务标识>`；规则工作区任务页也支持 `task` 查询参数。列表只展示最近 200 项，详情独立读取留存期内的原档案。列表读取失败不阻止档案查询，详情失败清除旧快照；任务、账号、探针或页面变化取消旧请求，迟到结果不能恢复旧内容。关闭只移除 `task` 参数并保留视图、其它条件和锚点；浏览器历史、复制链接及刷新可恢复原任务。详情将执行截止与记录保留截止分开显示；回读、解除与规则核实仍需各自的当前设备资格，不因历史档案可读而获得执行许可。

采集器任务记录支持 `/network?view=tasks&task=<id>` 的独立详情链接，受理入口引用原任务，执行和保留截止分别展示。共用详情读取器在任务、工作视图、账号或路由变化时取消旧请求，不以近期列表代替档案；本地结果仅供追溯，不提供设备写动作。
