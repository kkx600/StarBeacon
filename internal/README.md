# 星烽 StarBeacon 服务模块

一个 Go module，多个运行角色。`cmd` 只选择角色，`app` 负责生命周期和依赖组装；业务包不读取环境变量、不启动全局连接池。使用 Go 1.26.8，目录内注释和业务错误使用简体中文。

| 包 | 当前职责 | 依赖边界 |
| --- | --- | --- |
| `config` | 环境配置、角色必填项和传输边界校验 | 标准库 |
| `app` | 启动、就绪检查、HTTP/gRPC 服务和有界退出 | 组装各角色 |
| `httpapi` | 会话、CSRF、登录限流、可信单层代理地址、统一错误和请求标识 | `SessionStore` 由消费方定义；PG/本地实现分开 |
| `platform` | 租户用户、探针、告警高级检索、事件调查、资产修订、运行／审计、规则／重放任务、通知、模型配置、冻结统计、私有分析、周期报告及分类留存 API | `store`、`httpapi` |
| `agent` | Linux 托管 AF_PACKET／外部 EVE、持久轮转、bbolt 队列、检查点、上传、心跳、本地管理、持久任务及受限原生检测 | 不持有平台数据库凭据；不修改管理网络、全局内核参数或网卡卸载设置 |
| `control` | 受限命令、Ed25519 签名域、摘要、载荷预算及控制唤醒 | 不接收任意系统命令 |
| `rulerelease` | 完整规则包装载、独立正反样本与同设备配置资格 | 不用装载通过或单份样本代替发布资格，不推断未测试流量 |
| `replay` | 样本对象／暂存、PCAP 容器边界、元数据及 PCAPNG 规范化 | GoPacket 与 S3 SDK；不向网络发包 |
| `packetarchive` | 独立 AF_PACKET 原包捕获、PCAPNG、分帧压缩、持久暂存队列、摘要及受限 TCP 会话导出 | 使用 GoPacket、Zstandard、bbolt 和 S3 SDK；不生成报文、不解密 TLS，不将快照称为完整会话 |
| `inventory` | 人工资产、资产组、网段、地址校验和不可变修订 | 不推断发现、身份、NAT 或攻击成功 |
| `searchfilter` | 受限 Wireshark 风格类型化 AST 与字段目录 | 不接受任意 ES DSL，不等同完整逐包语法 |
| `assessment` | 人工研判状态、结论、攻击结果及依据契约 | 不改写原始告警，不授予自动响应权限 |
| `incident` | 告警唯一关联、责任分派、调查修订、结构化结案及重开 | 不复制原始告警，不授权设备动作；活动案件历史受保护 |
| `accounts` | 租户用户目录、创建、角色和使用状态、公开回执及修订契约 | 固定数据库函数原子提交权限、会话撤销和审计；密码只写，支持当前密码验证、自身修改与成员重置，登录验证绑定修订；不包含删除、改名 |
| `triage` | 单告警白名单材料、冻结摘要、严格模型结论、实际事实引用及自报分数 | 不发送原始载荷，不推断攻击成功，不授权设备动作 |
| `decision` | CEL 策略、持久影子评估与独立管理员处置确认 | 影子结果不授予执行权限；人工确认必须重新核对原材料和当前设备资格 |
| `response` | 固定 HTTPS 设备身份、独立租约、原生 TTL、条件解除与回读 | 受理及设备配置回读不证明真实流量阻断；保护本机与平台管理通道 |
| `rulegen` | 自然语言／PCAP／HTTP Raw 模型候选、材料摘要、受限动作与 SID 契约 | 候选仍需独立原生装载和正反样本发布资格 |
| `secrets` | AES-GCM 凭据封装及租户／对象／修订绑定 | 密钥由部署注入，不返回明文凭据 |
| `outbound` | TLS、目标允许范围、DNS 与出站连接约束 | 不使用环境代理，不允许云元数据地址 |
| `notify` | 邮件、办公机器人、Webhook 与 Syslog 摘要协议 | 渠道受理、写入与已读／落盘分开 |
| `llm` | 官方 SDK 生成接口适配与有限连接验证 | 协议与用量边界，不授予安全动作权限 |
| `analytics` | 完整告警统计快照与计数校验 | 不推断攻击成功或登记资产的历史状态 |
| `assistant` | 自然周期、日历计划、冻结证据、来源引用与 HTML 报告 | 不提供原包、自动授权或未经验证的领域结论 |
| `jobs` | River 事务队列、模型分析及持久日历调度 | 单次收费执行、租户配额、配置修订核验、错过范围及未知结果 |
| `retention` | 十一类策略、默认 180 天与未来对象生效边界 | 不将缓存 TTL 视为业务留存，不重算存量 |
| `hosthealth` | 实际宿主资源与进程运行状态 | 不向 API 暴露凭据或宿主路径 |
| `testpcap` | 保留示例地址的测试帧 | 仅用于自动化与工程验收，不作为生产遥测 |
| `clientip` | 明确 CIDR 对端的单值客户端地址、统一审计和限流来源 | 标准库；默认忽略转发头，不解析任意代理链 |
| `transport` | TLS 1.3、CA 校验和证书内规范探针身份 | 不接受消息自报租户作为身份 |
| `contract` | 来源身份、批次摘要、稳定事件 ID、精确 ACK 和索引命名 | 同时用于采集、接入与分析 |
| `ingest` | 实时核验注册状态和路由；PubAck 后确认接收 | 业务数据进入持久流，控制心跳独立 |
| `bus` | 命名空间、JetStream 持久流和共享索引消费者 | 容量背压，不丢弃未处理数据 |
| `traffic` | 从原始 EVE 提取有界会话时间、双向计数、MAC 集合及协议展示元数据 | 不增加未实现索引、不补造原包、方向或 TLS 解密结果 |
| `normalize` | EVE 标准化、64 位标识、实际 IP/MAC 和原文保留 | 不推断攻击成功、出站时间或解密状态 |
| `mcpaccess`／`mcpserver` | OAuth 服务身份、官方 MCP SDK、现有业务只读工具 | 不接受调用方租户；不透传令牌、不返回原始载荷、不执行设备动作 |
| `store` | pgx 租户 RLS、分类期限与受保护历史回收、ES 索引与有界检索 | 显式 SQL；ES Bulk 逐项确认 |
| `worker` | 解析、索引、持久隔离及通知 outbox 调度 | 索引通知持久接收后 DoubleAck；通知独立消费与逐接收人回执 |
| `admin` | Goose 迁移、最小权限账号、初始化、离线有效管理员恢复和开发证书 | 独立管理凭据；运行角色没有迁移权限 |
| `telemetry` | Prometheus 指标和低基数标签 | 不用 IP、租户、规则或载荷作标签 |
| `model` | HTTP 与持久数据契约 | 不暴露 SDK 类型 |
| `buildinfo` | 构建版本与提交标识 | 由编译参数注入 |

后续领域包按实际实现落地：资产自动发现与地址关系、规则来源与自动灰度编排、大规模原包索引与长连接取证、模型领域评测与调查工具、持续决策与多级审批、商业设备响应适配与真实流量核验、原始事件与进程日志全集归档／历史补发、MCP 扩展工具与资源、报告调度实际恢复验收／审批发布和全域留存作业。当前代码与缺口逐项见[功能实现与验收状态](../docs/功能实现与验收状态.md)。接口由真正调用者提出；不提前堆砌无行为的空服务、空适配器或返回成功的占位方法。

新增持久化状态使用 `migrations/` 中递增 Goose SQL。新增 API 同时维护 `api/openapi/`；跨采集器通信修改 `api/proto/` 后通过 `make generate` 生成。安全、事务、投递和字段语义的测试保留在对应包，真实依赖联调位于 `tests/integration/`。完整启动与工程范围见[工程实现与开发](../docs/工程实现与开发.md)。

索引 Worker 必须使用最小权限 PG 运行账号读取类别策略，不再依赖凭据功能是否启用。ES 自有索引模板关闭匹配索引的自动创建，防止缺失映射或生命周期策略的隐式索引；模板所有者和保留策略不匹配时启动／写入失败，不覆盖已有定义。新建日期分区固定所用策略，既有分区不随配置发布重新起算。

`rulegen` 定义冻结材料、分配 SID、严格候选输出及来源引用约束；`replay/httpraw` 按原字节构造离线 TCP 样本并保留合成来源，`replay/context` 只解析到传输层提取有界载荷。生成任务、共享预算、SID 注册、队列与审计在 PostgreSQL 事务内提交。`jobs/RuleGenerationWorker` 使用官方 SDK 发出一次严格 JSON 请求，结果未知时不再调用；原生语法与检测效果沿用独立目标探针测试和发布资格。
