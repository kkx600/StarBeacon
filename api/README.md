# 星烽 StarBeacon 接口契约

当前 HTTP 接口使用 OpenAPI 3.1，本目录 `openapi/` 是实际接口的权威契约。[接口与数据契约](../docs/接口与数据契约.md)描述完整目标范围，其中尚未实现的接口不能作为当前可调用入口：

- [平台 API](openapi/platform.json)：身份、租户用户与密码维护、探针启停与心跳视图、告警高级检索与字段目录、资产／资产组／网段修订、依赖／宿主健康、规则包、签名任务、重放样本、操作／登录审计游标、通知渠道与推送日志、模型配置与连接验证、冻结统计与态势展示、私有分析对话、周期报告及持久报告计划、分类留存策略。
- [采集器 API](openapi/collector.json)：独立本地身份、宿主机健康、实际网卡、采集目标保存、独立本地重放及任务回执。

两端使用各自的 HttpOnly Cookie。写请求及 `POST /alerts/search` 需要 `X-CSRF-Token`；登录由同源校验和限流保护。客户端只传业务筛选，不指定租户、ES 索引或任意 DSL。长度口径按字段契约区分：业务名称通常最多 128 个 Unicode 字符，高级过滤表达式最多 4096 个 UTF-8 字节，普通 JSON 请求体最多 2 MiB，EVE 单条最多 1 MiB。Flow ID、源偏移、序号与字节计数使用字符串；有界修订与 token 用量使用整数。原始 EVE 仅向平台管理员返回；通信证据权限尚未细分。

`/healthz`、`/readyz`、`/metrics` 是运维接口，HTTP 只监听回环。外部同源入口仅放行该端对应的 `/api/` 路由，监控接口另由受控管理入口访问。Go 不内置前端静态页；同源代理须保留原始 Origin，并将该端 `SB_ALLOWED_ORIGIN` 配置为实际外部来源（无路径，生产为 HTTPS）。就绪检查代表当前依赖可用，不证明 Suricata 捕获质量、队列无积压或生产容量合格。

[采集器 Protobuf](proto/starbeacon/sensor/v1/sensor.proto) 定义七种 RPC：`UploadEvents` 与 `GetRoute` 由事件接入进程提供，`Control`、`DownloadReplaySample` 与 `UploadPacketArchive` 由主平台 gRPC 服务提供。`RenewCertificate` 由主平台提供，`CertificateStatus` 在主平台和事件接入端核对当前实际指纹。原包上传使用独立连接及有界传输额度，与控制连接分开。mTLS 证书唯一绑定租户、探针和注册代次；每个控制帧及样本流核验注册启用状态，不接受消息自报租户。

控制连接使用受限 `sensor.command.v1` JSON：租户、探针、注册代次、任务身份、种类、投递期限和固定业务载荷；不传 shell 命令。Ed25519 签名覆盖 `StarBeacon/sensor.command.v1\x00` 加原始 JSON，`payload_sha256` 是原始载荷的 32 字节 SHA-256。设备核对预置信任公钥和身份后同步保存接受状态，回执采用 `sensor.receipt.v1`，最多 64 KiB；平台 ACK 精确确认原始回执字节摘要。断线重传不重复执行，终态回执不可改写。签名密钥与 mTLS 私钥独立；设备不持有平台命令私钥。

任务类型包含 `applications.apply`、`capture.configure`、`diagnostics`、`rules.validate`、`rules.replay`、`rules.apply` 和 `rules.reconcile`。采集配置任务冻结期望修订、实际配置文件摘要及采集参数摘要，平台和设备分别核对注册代次、在线观测和真实网卡；配置变更冲突时拒绝执行，成功回执必须包含一致的期望／生效参数和原生进程状态。发布必须提供同一探针、注册代次、完整修订、检测配置与一天内的三份实际回执：装载检查、命中样本、未命中样本；正反样本摘要必须不同。平台核对原始命令签名及回执，缺少资格时返回 409 `release_validation_required`。发布及核实绑定最新观察到的规则文件摘要，设备执行前再次核对；原生装载数量和文件回读符合预期才返回成功。核实只重新装载中断事务的当前文件，不允许指定新规则或路径；原中断回执保留，独立核实依据解除发布阻塞。固定计划修订的分批编排见[规则分批发布](../docs/规则分批发布.md)；生产规模灰度效果、自动故障回退和完整规则来源管理仍待交付与验收。重复创建使用 `Idempotency-Key`；同键不同参数返回冲突。仅尚未投递的任务可取消。平台任务与本地 `localtask_` 任务分属不同信任来源，本地执行结果不进入平台待确认队列。发布与核实的真实远程验收记录见[测试覆盖与验收记录](../docs/测试覆盖与验收记录.md)。

PCAP 上传接口在认证／CSRF 后接收 `application/octet-stream`、`Content-Length` 与 URL 编码的 `X-Filename`，24 字节至 100 MiB。下载 RPC 只能用于本设备有效且已投递／执行中的重放任务，每块最多 128 KiB，连续偏移，客户端核验签名中的最终长度和摘要；终态任务不能继续下载。没有通用对象存储凭据下发，也没有允许用户选择任意服务端文件路径的参数。完整限额与部署见[PCAP 重放与规则验证](../docs/PCAP重放与规则验证.md)。

审计默认最近 7 天，单次最多 31 天／100 行，使用时间与字符串 ID 的稳定游标；登录记录对应密码验证结果，不代表会话一定创建成功。平台健康返回 `runtime` 与 `services`，缺失资源不是推定为零。

通知与模型写操作仅限管理员，凭据只写并加密保存，不回显完整 webhook 地址、API key 或邮件密码。渠道修订与 outbox、模型连接验证、业务分析与规则生成共享的修订／幂等／UTC 日提交预算及未知结果分别建模；HTTP 受理不等于通知已读，模型连接验证通过不等于领域研判通过。出站 Syslog 可订阅本租户告警摘要、检测质量事件、操作审计和登录审计，持久保存投递结果；办公渠道可显式订阅安全告警或检测质量事件。历史渠道不自动扩大订阅范围，不代表入站 Syslog 或全量原文归档已经实现。

统计接口使用固定半开窗口和完整 ES 聚合，失败不补零。分析作业按租户与创建人隔离，管理员不能读取同租户其他人的对话；日报、周报、月报采用指定时区的自然周期，支持手动生成和持久日历计划。计划配置冻结时区、时间、模型修订与持续授权；停机恢复只提交最近完整周期并记录错过范围，停用不撤销已提交报告。模型调用通过 River 与业务记录同事务入队，已发送请求取消后可能为未知结果，不自动重试可能计费的调用。HTML 报告是经认证的下载接口，不代表审批发布、PDF 或外部投递。

分类留存提供管理员查询、五分钟影响预览及精确幂等发布，默认 180 天、可设 1–3650 天；仅支持未来对象。告警与网络事件按租户 UTC 日期分区首次创建时固定 ILM，既有分区不改变；已接入的其他类别按新记录首次创建固定期限。活动配置不按历史期限删除。当前不提供存量重算、全域保全或备份销毁接口。

`python3 scripts/check_alignment.py --check` 比对实际平台注册、采集器注册的业务操作及工程路由，防止未注册接口进入契约或真实入口漏写。功能范围及缺口见[功能实现与验收状态](../docs/功能实现与验收状态.md)，该静态检查不代替真实 API 验收。

生成器版本由 Makefile 固定。修改 `.proto` 后运行 `make generate GO=/绝对路径/go PROTOC=/绝对路径/protoc`；HTTP 变更同时维护本目录 OpenAPI。

应用识别规则入口为 `/api/v1/application-rules`，包括当前目录、不可变修订、管理员维护、候选定义输入验证和全部启用规则材料验证。请求最多 32 KiB，拒绝重复／未知字段；维护要求 CSRF、幂等键与期望修订，验证只有在原子审计成功后返回结果。回执注明用户提供的材料、缺测／候选／冲突及摘要；输入验证不修改流量归因、不发布探针规则、不授权网络动作。独立快照和单探针签名部署接口为 `GET /application-rules/snapshot`、`POST /sensors/{id}/application-rules`（平台 API 前缀），冻结完整目录、注册代次和探针状态。实际 EVE 分类独立上报并按原部署复算，原字节与历史事件保持不变；该结果不等于流量字节计量。详见[应用识别规则与输入验证](../docs/应用识别规则与输入验证.md)。

流量记录通过 `POST /api/v1/traffic/search` 独立检索，`GET /api/v1/traffic/fields` 提供协议数据集目录。返回严格校验的精确分页和有界会话／协议详情；只读账号不能读取原始 EVE。时间、计数、MAC 集合与 TLS／DNS 语义见[流量检索与会话观测](../docs/流量检索与会话观测.md)。

HTTP Raw 的两端二进制入口为 `POST /api/v1/replay/samples/http` 和 `POST /api/local/v1/replay/samples/http`，上限 2 MiB，保存原始字节摘要与合成 TCP 来源。平台通过 `/api/v1/rule-generation/jobs` 提交、读取、取消和人工采纳候选；租户及当前管理员所有者隔离，冻结模型修订和样本摘要。严格 JSON 调用不自动降级或重试；候选不会直接发布。接口字段、SID 与验证链详见[AI 规则生成与样本验证](../docs/AI规则生成与样本验证.md)。

单告警模型研判使用 `/api/v1/alerts/{id}/triage` 和 `/api/v1/alert-triage/jobs/{id}`，提供持久创建、所有者历史、详情与取消。实际调用前回读精确告警来源；输出仅允许实际引用与待复核建议，不发送原始载荷，不授权封禁。详见[告警模型研判](../docs/告警模型研判.md)。

两端原包目录、详情、下载与逐包协议查看分别位于 `/api/v1/packet-archives` 和 `/api/local/v1/packet-archives`，仅管理员可访问；本机已确认上传并回收原件的记录不能再次本机下载。平台 `POST /api/v1/packet-archives/session-export` 要求 CSRF、固定双端身份及明确导出模式；完整性不足返回 422 和实际原因，成功返回经过 SHA-256 核验的 PCAPNG。上传只在版本对象及目录持久提交后返回精确确认，不下发对象存储密钥。限制与完整性口径见[原包归档与会话导出](../docs/原包归档与会话导出.md)。

租户用户 API 位于 `/api/v1/users`，仅允许当前有效管理员访问。创建密码为只写字段；编辑只接受角色、使用状态及预期修订，要求幂等键。用户权限、会话撤销、审计与公开回执同事务提交，跨租户目标或游标返回 404，冲突返回 409，到期回执返回 410。当前账号公开修订读取使用 `GET /api/v1/auth/account`，自身修改使用 `POST /api/v1/auth/password`，管理员重置其他成员使用 `POST /api/v1/users/{id}/password`。两种密码写入均验证操作者原密码、CSRF、预期修订和幂等键；持久验证预算为每人每 60 秒 10 次，过量返回 429 与 `Retry-After: 60`。成功原子撤销目标全部会话，失败回滚密码、撤销及审计。完整契约见[用户管理与权限](../docs/用户管理与权限.md)。

告警与协议元数据导出使用 `POST /api/v1/alerts/export`、`POST /api/v1/traffic/export`，沿用列表条件并返回固定 PIT 的完整 CSV；上限 10,000 条／8 MiB，无原始 EVE、载荷和 PCAP。读取期间回核当前会话并记录准备审计，超限或不完整不提供部分文件；见[检索快照与元数据导出](../docs/检索快照与元数据导出.md)。

逐包协议查看使用两端 `GET /packet-archives/{id}/packets/{number}`（各自 API 前缀）。仅管理员可访问，每次完整核验指定归档后返回一个实际捕获帧和最多 16 层协议字段；包序号为 1–1,048,576 的规范整数，禁止查询参数。与下载共享并发和超时额度；发送前复核会话与目录并保存 `pcap.inspect.request` 审计，审计失败不返回原字节。回执为 `packet.inspect.v1`，含目录、原始归档及帧摘要、纳秒捕获时间、实际长度、截断／VLAN 卸载状态、原字节和明确解析边界。浏览器核验来源及 SHA-256 后展示，关闭或切换时取消请求。非随机包索引、TLS 解密、校验和验证或全部应用协议资格；完整契约见 OpenAPI 及[原包归档与会话导出](../docs/原包归档与会话导出.md)。

`POST /api/v1/sensors/{id}/response-tasks` 支持管理员显式授权的 `response.block`、`response.read` 和 `response.revoke`，使用唯一规范请求键、CSRF、当前账号与注册身份核对。封禁目标、配置摘要与绝对期限冻结；回读和解除只引用原封禁任务，设备 GET 回读快照以 `traffic_effect=not_observed` 保存。采集器健康中的 `response_connectors` 仅提供身份、摘要、TTL 和状态，不含凭据或管理地址；本地控制台只读。接口没有自动模型执行授权。通用协议、配额、私有配置和真实设备边界见[HTTP 联动与限时封禁](../docs/HTTP联动与限时封禁.md)。

`GET /api/v1/tasks/{id}` 为管理员读取本租户指定任务档案，独立于最近 200 项列表。`expires_at` 是执行截止，`retain_until` 是操作留存策略在创建时冻结的记录保留截止，默认 180 天；已过留存期、跨租户与已删除对象统一返回 404。读取原联动授权时核对命令摘要、原注册代次和绝对期限，不依赖当前设备在线、ES 或当前签名密钥；详情不返回管理地址、凭据或完整命令。查询不接受额外参数，预算 5 秒；只有从未投递的到期任务可以终止为 `expired`，不变更已经投递或完成的原回执。

`GET /api/local/v1/tasks/{id}` 为本地管理员独立读取指定任务档案，链接为 `/network?view=tasks&task=<id>`；受理后的重放入口打开原任务，不依赖最近 200 项列表。新任务接收时冻结 `retain_until`，默认 180 天；`SB_TASK_RETENTION_DAYS=1–3650` 只影响后续本地任务，平台仍使用其租户操作留存策略。`retention_protected` 标明未获平台确认、仍在执行或未取得独立核实结果的任务暂不清理；该保护不表示执行成功或联动授权。到期且可清理的记录不对外展示，详情返回 404；存储或绑定损坏返回 503。只读列表每次最多扫描 1000 条历史索引，返回最多 200 项；指定主键不受该窗口影响。物理清理在接收任务时有界执行，启动及每分钟另有独立周期回收；续点持久保存，未确认与待核实记录继续保护。不返回完整命令、规则原文或凭据。

生产探针注册使用 `/api/v1/sensor-enrollments` 与设备专用 `/exchange`；目录、令牌撤销、指定探针证书及吊销入口见 OpenAPI。设备交换拒绝浏览器上下文，仅接受固定令牌与 CSR；未知签发不盲目重签。采集器 `/api/local/v1/identity` 只读本机指纹和续签窗口。证书记录按操作策略留存，默认 180 天；证书认证有效期默认 24 小时，两者独立。部署、恢复及实际测试范围见[探针注册与证书](../docs/探针注册与证书.md)。

`GET /api/v1/sensors/quality-events` 查询当前租户的检测质量历史，支持 `[start,end)` 时间、探针、注册代次与类型条件；窗口最多 31 天，每页 20 条，最多前 10,000 条。精确数量与原生指标使用字符串；重复／未知参数、来源矛盾或不完整分片拒绝返回部分结果。`QualityCounter.observed_resets` 是可选的当前进程已观测累计下降水位，不代表全部实际复位；完整水位用于跨心跳区间核对。实时快照和冻结历史的时钟语义、通知及留存边界见[检测质量事件](../docs/检测质量事件.md)。

规则分批发布通过 `/api/v1/rule-rollouts` 创建与读取游标目录，`/{id}` 读取固定目标和执行修订，`/{id}/stop` 登记原因并停止后续提交。均限定本租户管理员；创建只接受本人批准的停用计划及固定修订，活跃目标预留期间拒绝直接编辑原计划。每个目标仍独立通过原生装载、正反样本和发布资格；窗口结束后的新心跳与实际摘要核对后才推进下一批。停止与已取消、受理与实际生效分开记录，原输入重取不重复发布。字段和限额见 [OpenAPI](openapi/platform.json)，业务和留存见[规则分批发布](../docs/规则分批发布.md)。
